# ADR 0001 — Stack & Design Decisions

**Date**: 2026-04-27
**Status**: Accepted
**Deciders**: 사용자(noah) + Aria(PM 에이전트)

## Context

K-Entertainment Job Bootcamp 랜딩 페이지(`/kenterbc`) 구현 시작 시점. PRD는 Next.js 14 / Tailwind / Supabase 를 명시했으나, 플랫폼 기본값(Vercel 2026)과 사용자 선호를 반영해 일부 결정을 갱신한다.

## Decisions

### 1. Framework — Next.js 16 (App Router)

PRD는 14를 명시했으나 16으로 채택.
- **Why**: Cache Components / PPR / 최신 캐싱 API 가 전환율(LCP, INP)에 직접 기여. 사용자 명시 동의.
- **Trade-off**: Next.js 14 → 16 마이그레이션 가이드의 일부 패턴 변화. 큰 코드베이스가 아니라 영향 적음.

### 2. Backend — Supabase

- **Why**: 사용자 기존 경험·계정 보유. PRD 명시. 어드민 UI(테이블 뷰, RLS 편집)가 빠른 운영에 유리.
- **거부된 대안**: Vercel Marketplace (Neon Postgres + Auth) — 사용자 학습 비용 발생.

### 3. Theme — Dark mode only (no light mode)

- **컬러 팔레트**: 블랙 배경(#0A0A0F 계열) + **퍼플 / 핑크 / 남보라** 그라데이션 액센트.
- **거부**: 골드 액센트 (사용자 거부), 라이트 모드 (사용자 명시 거부).
- **Why**: K-pop / 엔터 톤, Linear/Vercel 류 프리미엄 감각, 외국인 타겟의 "한국 트렌디" 인식과 정합.

### 4. Deployment — 단독 Next.js 앱 (codebase 분리)

- **단독 앱**: 본 리포지토리(`/Users/noah/Kenter_bootcamp`)에 새 Next.js 프로젝트 생성, 별도 Vercel 프로젝트로 배포.
- **퍼블릭 노출 경로**: **(B) 새 도메인 단독 운영** — 사용자 결정 (2026-04-27).
  - 개발 단계: 임시 Vercel URL (예: `kenter-bootcamp.vercel.app`) 로 진행.
  - 배포 단계: 도메인 구매 후 Vercel 프로젝트에 연결.
- **거부된 대안**: (A) dropdown.xyz/kenterbc rewrite — 브랜드 독립성 우선.

## Consequences

- 기본값: Next.js 16 + Tailwind v4 + Supabase JS v2 + Vercel.
- 다크 전용이라 라이트 모드 토큰·테마 스위치 불필요 → 디자인 시스템 단순화.
- 1,100,000 → 880,000 KRW 가격은 정적 데이터로 도메인 레이어에 박제(추후 변경 가능하도록 설정 분리).

## Decisions — Content & Commerce (2026-04-27 추가)

### 5. 가격·결제
- 가격: **1,100,000 → 880,000원** (VAT 포함). 카운트다운/타이머 **없음**.
- 결제 수단: **계좌이체만** (예금주 **DEEPI**). 카드/해외카드/USD **미지원**.
- 희소성 신호: **"선착순 마감"** 톤 강조 (사용자: *"마음 졸이게 하고 싶다"*).

### 6. 환불
- **수강 시작 7일 이내 100% 환불.** 그 외 비율 환불은 추후.

### 7. 프로그램 범위
- 부트캠프 + **이력서 / 포트폴리오 / 면접 코칭** 포함 (취업 지원 패키지).

### 8. 멘토
- **2명 확정**: 무대 음향 감독 1, 비주얼 디렉터 1.
- **1명 예정**: 현업 네트워킹 멘토.
- 이름·경력은 추후 입력 — 현재는 placeholder.

### 9. 사회적 증명 노출 정책
- **개별 공연/아티스트/IP 노출 X**.
- 노출 가능: 누적 **공연 횟수**, 누적 **관객 수** (수치는 사용자가 추후 제공).

### 10. 후기 (Testimonials)
- 12월 1기 수강생 발언을 **익명화·요약 변형** 형태로 노출.
- 표기: 이니셜 + 국적 + 지망 직군만 (전체 이름 사용 X).
- **Sage 플래그**: 표시광고법(공정거래위원회)·외국인 유학생 보호 측면에서 위험 완화 — *"수강생 인터뷰 발췌 (개인정보 보호를 위해 익명화)"* 디스클로저 함께 노출.
- 만족도 점수: 추후 사용자 제공.

### 11. 수료증·커뮤니티
