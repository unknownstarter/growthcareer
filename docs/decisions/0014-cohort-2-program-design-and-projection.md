## v1.1 정정 요약 (2026-07-04)

노아 정정 3건 반영:

1. **Cowork 12% commission 유지** (v1 오류 = "B0001 dropped 반영 없음"). 1기 학생 대부분 Cowork 채널 유입, 2기도 같은 채널 가정. 매출 x 12% 비용 계상.
2. **셰르파 = 별도 트랙 아니라 강사 중 한 명이 진행하는 하나의 단과** (v1 오류 = "Fan to Pro + 셰르파 이중 트랙" 이해). 재해석: Growth Career 우산 아래 여러 단과 존재, 각 단과 = 5주 = 강사 1명. 올인원 = 여러 단과 조합 + 할인.
3. **강사료 = 5회 flat 250만원 + VAT 별도** (v1 오류 = "1기 계약서 §4 tier 재사용"). 새 tier = 인원 무관 flat 250만원, VAT 10% 별도 = 우리 부담 275만원 or 원천징수 3.3% 후 net 24,175,000원.

시나리오 A~D 전면 재계산. Baseline B 세후 순익 = 13.46M (v1 19.575M 에서 하락, Cowork 12% + 실측 반영).

## 진단 요약 (한 줄)

Growth Career 우산 아래 **여러 단과** (각 5주 강의 + 페스티벌 참관 2회 옵션 + 회고). 2기는 최소 2단과 (Fan to Pro 공연 실무 + 셰르파 뮤직 비즈니스) 로 시작, 시나리오 D 는 3단과 확장. 학생 = 단과만 or 올인원 (여러 단과 조합 + 할인) 두 유형. 강사료 신규 tier = 5회 flat 250만원 + VAT 별도. **Baseline B 세후 순익 13.46M (순익률 53%)**. **손익분기점**: 단과당 4명 (250만 강사료 + Cowork 12% + 마케팅 5% 커버).

## 프로그램 구성 (재해석)

### 우산 구조 = Growth Career 아래 여러 단과

- 단과 (course) = 5주 강의 + 페스티벌 참관 2회 옵션 + 회고. 강사 1명 (또는 팀).
- 학생 = 단과 1개만 선택 vs 여러 단과 조합 (올인원, 할인 적용).
- 2기 스타트 = 2단과 확정 (아래). 3단과 확장 = 시나리오 D.

### 단과 A: Fan to Pro 공연 실무 (5주)

**Why**: 1기 브랜드 승계. 사운드 + 현장 실무 + 페스티벌 참관.

**구성 (5주)**

| 회차 | 형식 | 시간 | 담당 |
|---|---|---|---|
| 1주 | 강의 (기본 이론) | 2h | 이제향 or 박성철 |
| 2주 | 강의 (심화) | 2h | 이제향 or 박성철 |
| 3주 | 페스티벌 참관 1 + 회고 | 반나절 + 2h | 강사 + 운영진 인솔 |
| 4주 | 강의 (뮤직 비즈니스 연결) | 2h | 게스트 or Nino 발췌 |
| 5주 | 페스티벌 참관 2 + 최종 회고 + 수료식 | 반나절 + 2h | 전체 |

**참관 대상 페스티벌** (Echo 리서치 대기):
- 이제향 2025~26 참여: 서울 히어로락페스티벌, MBC 대학가요제, 화성 인디뮤직 페스티벌 등
- 박성철 2025 참여: SBS 가요대전 썸머 유니팝, 사운드베리 페스타 25 등
- 2026 하반기 ~ 2027 상반기 K-pop 대형 페스티벌 스케줄 확정 필요

**가격**: 실입금 800,000원 (얼리버드/일반 통합 실효)

### 단과 B: 셰르파 뮤직 비즈니스 (5주)

**Why**: Nino (Sherpa Music CEO, 27년차) 대표가 뮤직 비즈니스 5주 단과 담당. 실무 A&R / 퍼블리싱 / 창작자 매니지먼트 특화.

**구성 (5주)**

| 주차 | 주제 (제안, Nino 확정 필요) |
|---|---|
| 1주 | 뮤직 산업 개괄 + K-pop A&R 사례 |
| 2주 | 음반 기획 / 제작 프로세스 (I.O.I ~ 워너원 ~ 아이즈원 실전) |
| 3주 | 퍼블리싱 + 작가 계약 (Hi-Hat / Sherpa Music 290여팀) |
| 4주 | Visual Director + Creative Direction (이승윤 3집 사례) |
| 5주 | 해외 오디션 + 데뷔 프로세스 (JTBC Project7 마징시앙) + 수료식 |

**가격**: 실입금 800,000원 (단과 A 와 통일)

### 단과 C (시나리오 D 만): 신규 도메인 단과 (5주)

- 추후 확정. 예: 라이브 프로덕션 감독 / A&R 전문 / 매니지먼트 실무 등.
- 시나리오 D 에서만 도입 가정.

### 올인원 패키지

**Why**: 여러 단과 조합 = 산업 전체 조망. 조합 시 할인 = 학생 유인 + 매출 총액 증가.

**구성 및 가격 (제안, 노아 결정)**:
- 올인원 2단과 (A+B): 800,000 x 2 x 0.85 = **1,360,000원** (15% 할인)
- 올인원 3단과 (A+B+C, 시나리오 D): 800,000 x 3 x 0.80 = **1,920,000원** (20% 할인)
- 최소 10% ~ 최대 25% 사이 재검토

**결제 flow**: 단일 결제 (1개 항목). `applicants.paid_amount_krw` 단일 row + `enrollment_courses` (ADR 0013 B0068) 로 매핑.

## 재무 파라미터 (v1.1 재정의)

### 학생 실입금 가격

- 단과 1개: **800,000원** (얼리버드/일반 통합 실효)
- 올인원 2단과: **1,360,000원** (15% 할인)
- 올인원 3단과: **1,920,000원** (20% 할인, 시나리오 D 만)

### 강사료 (신규 tier)

- **단과당 강사 1명 = 5회 flat 250만원 + VAT 10% 별도 = 275만원 지급 (부가세 강사 부담)**
- 협상 여지 X. 안 받으면 다른 강사 섭외.
- 세금 처리:
  - 강사 사업자등록 있음 → 세금계산서 275만원 지급 + 매입세액 공제
  - 강사 개인 → 원천징수 3.3% (250만원 - 82,500원 = **net 지급 2,417,500원**), 매입세액 X
- **프로젝션 단순화**: 우리 부담 = 강사료 250만원 x 단과 수 (매출 부가세 실납부에 매입세액 반영)

### Cowork commission

- **매출 x 12%** 유지 (v1 오류 정정)
- 단과 800,000 → Cowork 96,000
- 올인원 2단과 1,360,000 → Cowork 163,200
- 올인원 3단과 1,920,000 → Cowork 230,400

### 페스티벌 참관 비용

- 1기 없음. 2기부터 도입.
- **학생 1명당 3만원 x 2회 = 6만원** (최악 시나리오, 별도 예산 확보 가정)
- 파트너십 leverage 로 감축 가능 (노아 결정 대기)
- 셰르파 단과 B 는 참관 없음 가정 (뮤직 비즈니스 = 강의 중심)

### 마케팅 비용

- Cowork 12% + 인스타 광고 + 기타
- 프로젝션: **매출 5%** 추가 (Cowork 별도, 즉 총 마케팅 = 매출 17% 수준)

### 부가세

- Growth Career 학원 등록 X (Echo B0066 리서치) → 과세 사업자, 매출 부가세 10% 발생
- 실납부 = 매출부가세 - 매입부가세 → **매출 5% 가정**
- 학원 등록 (평생직업교육학원) 시 면세 전환 가능 (별도 검토, ADR 대상 X 이번 회차)

| **총 비용** | **22,491,200** | |

## 손익분기점 (재계산)

- **단과당 손익분기점**: 강사료 250만 + Cowork 12% + 마케팅 5% + 페스티벌 6만/인 커버 = **4명 (300만 매출)**
  - 계산: 학생 4명 x 800,000 = 3,200,000 매출. Cowork 384,000 + 마케팅 160,000 + 페스티벌 240,000 + 강사료 2,500,000 = 3,284,000 비용. 거의 breakeven
  - 즉 단과당 5명부터 흑자
- **단과 개강 최소**: 강사료 250만 flat 이므로 인원 무관 지급. 즉 **인원 미달 폐강 정책 = 노아 결정** (v1 은 20명 미달 폐강 이었으나 신규 tier 에서 재검토 필요)
- **폐강 시 매몰 비용**: 마케팅 + 플랫폼 약 100만 ~ 200만

## 리스크

### R1: 페스티벌 스케줄 확정 실패

- **트리거**: Echo 리서치 결과 참관 가능한 페스티벌 부재
- **완화**: 참관을 강의장 내 "가상 페스티벌 시뮬레이션" 또는 강사 촬영 실무 영상 세션으로 대체. 매출 영향 없음, UX 격하

### R2: 강사 부재 (Nino 스케줄 미확보)

- **트리거**: Nino 대표 스케줄 미확정 → 셰르파 단과 연기
- **완화**: 단과 A (Fan to Pro) 단독 진행 (시나리오 A'). 대체 강사 리스크 크므로 지양

### R3: 모집 미달 (단과 인원 부족)

- **트리거**: 단과당 5명 미만 → 강사료 250만 지급하면 적자
- **완화**:
  - 1기 수료생 recommendation 인센티브 (수강료 10% 캐시백)
  - 셰르파 브랜드 leverage (Sherpa Music 채널 홍보)
  - Cowork 채널 강화 (12% commission 유지)
  - 폐강 threshold 정책 확정 (예: 단과당 3명 미만 폐강)

### R4: 강사료 tier 협상 실패

- **트리거**: 신규 강사가 250만 flat 거부
- **완화**: 다른 강사 섭외. 이 조건 안 받으면 프로젝션 자체 재검토

### R5: 페스티벌 티켓 확보 실패

- **트리거**: 대형 페스티벌 티켓 sold out or 학생 단체 지원 불가
- **완화**: (a) 강사 초청 backstage 참관 (파트너십 leverage) or (b) 소형 인디 페스티벌 대체 (사운드베리 페스타 등)

### R6: Cowork 12% commission 지속성

- **트리거**: Cowork 채널이 2기 학생 유입 기여 실측 부재 시 12% 지급 근거 약화
- **완화**: 2기 신청 flow 에 UTM / referral 트래킹 삽입 (B0001 원래 목적). Cowork 유입 비율 측정 후 다음 회차 재협상

## 노아 결정 필요 (5건, v1.1 갱신)

1. **2기 시작일**. 페스티벌 스케줄 확정 후 (Echo 리서치 대기). default: 2026 년 10월 첫째 주 시작
2. **단과별 가격 통일 800,000원 유지 vs 셰르파 프리미엄** (v1 정정 반영: 셰르파 990,000 → 800,000 통일. 재검토 필요)
3. **올인원 할인율**. default 2단과 15% / 3단과 20%. 재검토?
4. **페스티벌 참관 티켓 확보 방식**. 파트너십 (강사 초청 backstage) 우선 vs 별도 예산 확보 (인당 60,000원)?
5. **2기 강사 구성**. 이제향 / 박성철 / Nino 3인 재계약 (1기 정원 미달 정산 이슈 해소 필요) + Nino 셰르파 단과 담당 + 신규 강사 (단과 C, 시나리오 D 만)?

**추가 결정 (v1.1 신규)**:

6. **단과 폐강 threshold**. 강사료 flat 250만 = 인원 무관 지급. 최소 개강 인원 (예: 3명 vs 5명 vs 10명) 확정 필요
7. **Cowork 12% 지속성 근거**. 실측 트래킹 (UTM) 도입 여부

## Rationale (v1.1 요약)

- **여러 단과 + 올인원 2 유형** = 올인원 = enrollment 1건 (여러 course_id 포함). 조인 테이블 채택 (ADR 0013 §3)
- **가격 통일** 800,000 = 단과별 프리미엄 격차 최소화 + 올인원 계산 단순화
- **강사료 flat 250만** = 인원 리스크를 우리가 감당 (강사 tier 협상 불가). 손익분기점 = 단과당 4명
- **Cowork 12% 유지** = 1기 유입 실적 기반. 지속성 근거는 UTM 트래킹으로 검증 (R6)
- **시나리오 B (Baseline)** 세후 순익 13.06M = 단과 A 15 + 단과 B 8 + 올인원 5. 순 인원 18명. 도달 가능한 realistic goal
- **시나리오 D 배제하지 않음** = 매출 max 원할 시 3단과 확장 (신규 강사 확보 조건부)
