# ADR 0019 — Fan to Pro 2기 가격 구조 + 손익(P&L) 시나리오

- Status: Accepted (노아 확정 2026-08-05)
- 관련: ADR 0014(2기 프로그램/프로젝션), ADR 0017 D5(코워크 커미션), ADR 0018(플랫폼 도메인/역할), `domain/pricing.ts`

> 원 단위 표기(§6.6). 이 ADR 은 2기 가격·비용·손익 시나리오와 그에 따른 운영 결정을 박제한다.

| A&R 단과반 | 확정 | Nino (Sherpa Music CEO) |
| 음향 감독 단과반 | 확정 | **최찬용** (E.K Ent. 실장, 음향 시스템 감독) — 2026-08-07 확정. 1기 이제향/박성철 아님(사람·회사 교체) |
| 올인원 (두 단과 모두) | 확정 | 위 둘 |

## 2. 가격 (확정)

| SKU | 정가 | 최종가 (할인) | 비고 |
|---|---|---|---|
| 단과 (각) | 660,000원 | **550,000원** | A&R, 음향 동일 |
| 올인원 | 1,320,000원 (= 660,000 × 2) | **990,000원** | 단과 2개 최종가(1,100,000) 대비 110,000원 절약 |

- 표기: 페이지에 정가 취소선 + 최종가. `₩` 심볼 사용.

## 3. 정원 / 개강 규칙 (확정)

- 각 과목 정원 최대 30명.
- **각 과목 개강 조건 = (그 과목 단과 신청 + 올인원 신청) ≥ 10명.**
- **올인원 1명 = 두 과목 최소인원에 동시 카운트** (양쪽 수강하므로).
- 10명 미달 과목 = 폐강.
  - **폐강 시 올인원 처리 (확정): 남은 개강 과목은 정상 수강 + 폐강 과목분만 부분환불(또는 차기 이월).** 전액환불 금지 (연쇄 폐강 방지).
- **개강 최소인원 = 10명 유지** (페스티벌 비용 제거 후 손익분기가 과목당 약 9명으로 내려가 10명이 안전 구간).

## 4. 비용 모델 (1기 실측 기반, 페스티벌 제거)

> ⚠️ **페스티벌 참관 티켓 비용(과목당 500,000원) 제외** — 노아 2026-08-05: 2기 미진행 예정.

| 항목 | 금액 | 고정/변동 |
|---|---|---|
| 강사비 (개강 과목당) | 2,500,000원 | 고정 (과목당) |
| 강의장 임대 (개강 과목당, ~20명 tier) | 1,000,000원 | 고정 (과목당). 21~30명 tier = 1,500,000원 |
| 코워크 커미션 | 결제 총액 × 12% | 변동 |
| 마케팅 | 매출 × 5% | 변동 |
| 플랫폼 (Vercel/Supabase/도메인) | 400,000원 | 고정 (기수) |
| 부가세 실납부 | 매출 × 10% − 강사 매입공제(250,000원/과목) | 변동 |
| 수료증 | 0 (Dropdown 자체 발급) | — |

**순익 공식**: `순익 = 0.73 × 매출 − 3,250,000 × (개강 과목수) − 400,000`
(0.73 = 1 − 코워크12% − 마케팅5% − 부가세10%. 3,250,000 = 과목당 고정 3,500,000 − 강사 매입공제 250,000.)

**손익분기**: 단과 공헌이익 = 550,000 × 0.73 = 401,500원/명. 과목당 BEP ≈ (3,250,000+플랫폼분) / 401,500 ≈ **9명**. → 최소 10명 = 흑자 구간.

## 5. 시나리오 매트릭스 (올인원 990,000 · 페스티벌 제거)

표기: (A&R단과 / 음향단과 / 올인원)

### A. 둘 다 개강 (각 과목 ≥ 10)

| 조합 | 순인원 | 매출 | 순익 |
|---|---|---|---|

| 5/5/5 | 15 | 10,450,000 | +728,500 |

### B. 한 과목만 개강 (나머지 폐강, 올인원 부분환불 → 단과가 550,000)

| 조합 | 매출 | 순익 |
|---|---|---|

### C. 전체 폐강 (어느 과목도 10명 미달)

- 수강료 전액 환불. **매몰비용(기지출 마케팅 + 플랫폼 400,000원)만 손실** — 유일한 실손실 케이스.

## 6. 핵심 결론

1. **개강만 하면 무조건 흑자** (최저 = 올인원 10명만 +327,000). 페스티벌 제거로 최소 10명이 손익분기 위.
2. **유일한 손실 = 전체 폐강** (어느 과목도 10명 못 채움) → 매몰비용 손실.
3. **올인원의 전략적 가치**: 1명이 두 과목 최소인원 동시 충족 → 폐강 방어. 매출은 단과2개 대비 110,000원 적지만 폐강 시 강사비 250만 매몰 회피가 더 큼. → **모집 초반 올인원 유도, 정원 근접 시 단과 유도.**
4. 5/5/5 는 최악이 아님 (최악 개강 케이스 = 올인원 10명만).

## 7. 미결 / 후속

- **코워크 커미션 base**: 결제 총액 12% 전액 vs 코워크 유입분만(≈4.8%). 본 ADR 는 보수적으로 12% 전액 사용. 서면 확정 필요 (ADR 0018/0017 D 계열 연계).
- **강사 재협상**: 강사비 250만/과목 = 재협상 성공 전제. 실패 시 손익 급변 — 계약 확정 후 모집 개시.
- **repo `pricing.ts` / ADR 0014 동기화**: 본 ADR 의 정가660/할인550 + 올인원 1,320/990 구조로 pricing.ts 갱신 필요.
- **백엔드 연결 미구현**: 현재 신청 UX 는 프리뷰 목업(`app/[locale]/f2p2-preview`). 신청 → applicants DB → 어드민 → LMS 파이프라인은 별도 작업. 2기 멀티 단과 선택 = 간이 정책 B(선택 slug 배열 저장) 미구현.
