## 1. 배경

v1.2 (Baseline B 적자 479만원) 보고 후 노아 판단: 800,000원 은 진입장벽. 660 또는 550 으로 낮추고 올인원 을 880,000 flat 으로 묶어 대량 판매 유도. 동시에 강사와 5회 flat 250만원 재협상 시도 (강사 총 수령 동일, 회당 단가만 낮춤).

## 2. 공통 파라미터 (v1.3)

### 강의 구조 (변경 없음)

- 회차: 회당 2시간 × 5주 (주 1회) = **5회**
- 세션 분리: 단과 A 시간대 + 단과 B 시간대 = 강의장 세션 2개
- 올인원 학생 = 두 세션 모두 참여

### 가격 (v1.3 2 subvariant)

| SKU | Subvariant 660 (원) | Subvariant 550 (원) | 회차 | 시간당 (660) | 시간당 (550) |
|---|---|---|---|---|---|
| 단과 A | 660,000 | 550,000 | 10h | 66,000 | 55,000 |
| 단과 B | 660,000 | 550,000 | 10h | 66,000 | 55,000 |
| 올인원 | 880,000 | 880,000 | 20h | 44,000 (33% off) | 44,000 (20% off) |

### 강사료 (v1.3 재협상 성공 가정)

- 강사와 합의 = 5회 flat 250만원 (회당 500,000원)
- 사업자 세금계산서 발행 → 청구액 2,750,000원 (2,500,000 + VAT 250,000)
- 노아 매입 공제 250,000원 → **실 부담 2,500,000원/강사**
- 강사 2명 = 5,000,000원 total (v1.2 대비 -20,000,000원 절감)

### 강의장 (변경 없음)

| 인원 tier | 시간당 (원) | 회당 (2h) | 5회 총액 (원) |
|---|---|---|---|
| ~20명 | 100,000 | 200,000 | 1,000,000 |
| 21~30명 | 150,000 | 300,000 | 1,500,000 |
| 31~40명 | 200,000 | 400,000 | 2,000,000 |

### 페스티벌 티켓 (변경 없음)

- 2 × 250,000 = 500,000원 (교육 원가 계층)

### Cowork 커미션 (변경 없음)

- 매출 × 40% × 12% = 매출 × 4.8%

### 마케팅 (변경 없음)

- 매출 × 5%

### 부가세 실납부

- 매출 부가세 = 매출 × 10%
- 매입 부가세 (재협상 성공 시): 강사 500,000 (250만 × 10% × 2강사) only
- 강의장 매입 공제 X 가정 (v1.2 유지)

### 폐강 기준 (신규)

- 세션별 인원 8명 미만 → 폐강 + 환급
- 시나리오 A (비관) 에서 단과 B 4명 + 올인원 2명 = 세션 B 6명 → 폐강 대상. 아래 A 는 폐강 케이스도 병기.

#### 3.A.2 시나리오 A 폐강 케이스 (세션 B 폐강)

세션 B (4명 단과 + 2명 올인원 = 6명) 폐강. 단과 B 학생 환급, 올인원 학생은 세션 A 만 참여 = 부분 환급 (단과 B 상당액).

- 매출 (660): 단과 A 8 × 660,000 + 올인원 2 × (660,000 상당, 단과 A 만) = 5,280,000 + 1,320,000 = 6,600,000
- 매출 (550): 5,280,000 대비 5,500,000 = 4,400,000 + 1,100,000 = 5,500,000
- 원가: 강사 1명 2,500,000 + 강의장 1 세션 1,000,000 + 페스티벌 1명 250,000 = 3,750,000
- 간접 (660): Cowork 316,800 + 마케팅 330,000 + 부가세 (660,000 - 250,000) = 410,000 → 소계 1,056,800
- 순익 660: 6,600,000 - 3,750,000 - 1,056,800 = **+1,793,200원 (흑자 179만원)**
- 순익 550: 5,500,000 - 3,750,000 - 928,000 = **+822,000원 (흑자 82만원)**

폐강 케이스가 오히려 순익 개선 (원가 절반 감축, 매출 감소는 부분 환급으로 완화). 폐강 정책 = 비관 시나리오 손실 방어 장치로 기능.

### 4.5 Fallback: 강사 재협상 실패 시 (v1.2 강사료 유지)

강사료 실 부담 = 5회 × 2,500,000 = 12,500,000/강사 × 2명 = **25,000,000원**
- v1.3 재협상 성공 대비 delta 강사료 = +20,000,000원
- 매입 부가세 delta = +2,000,000원 (강사 매입 250만 × 2강사 = 500만 → 2,500만 × 10% × 2 = 500만 은 재협상 성공, 실패 시 매입 (250만 × 5회 × 10% × 2강사 = 2,500,000) 추가 delta = +2,000,000)
- 재계산 편의: 실패 시 순익 = 성공 순익 - 20,000,000 + 2,000,000 = **성공 순익 - 18,000,000원**

**Fallback 순익 요약**

| 시나리오 | 성공 660 | 실패 660 | 성공 550 | 실패 550 |
|---|---|---|---|---|
| A 비관 14명 | +763,360 | **-17,236,640 (적자 1,724만원)** | -295,280 | **-18,295,280 (적자 1,830만원)** |
| B Baseline 28명 | +8,703,160 | **-9,296,840 (적자 930만원)** | +6,674,100 | **-11,325,900 (적자 1,133만원)** |
| C 낙관 44명 | +16,701,600 | **-1,298,400 (적자 130만원)** | +13,525,680 | **-4,474,320 (적자 447만원)** |
| D 초낙관 62명 | +25,935,120 | **+7,935,120 (흑자 794만원)** | +21,524,120 | **+3,524,120 (흑자 352만원)** |

**Fallback BEP (mix, 660)**: (7,500,000 + 20,000,000 - 2,000,000) / 699,286 = 25,500,000 / 699,286 = **36.5명 → 37명**
**Fallback BEP (mix, 550)**: 25,500,000 / 608,929 = **41.9명 → 42명**

재협상 실패 시 Baseline B 는 다시 적자권 (660 -930만, 550 -1,133만). 낙관 C (44명) 조차 660 도 적자 130만원. **재협상 성공은 필수 전제**.

| R5 | 부가세 매입 공제 (재협상 성공 시) 500,000원 만 계산. 강의장 세금계산서 발행 사업자 확보 시 추가 매입 공제 200,000~400,000원 가능 | 순익 +30만원 | 강의장 계약 시 세금계산서 발행 사업자 우선. v1.3 는 보수적으로 매입 공제 X |
| R6 | Cowork 유입률 40% 가정 유지. 550 subvariant 시 학생 저가 인식으로 Cowork 유입 저하 가능 (Cowork 신뢰 저하) | 순익 -50만원 | Cowork 협의 시 660 price sheet 제시. 550 은 얼리버드 로만 노출 |

## 6. 노아 최종 결정 필요 (v1.3)

### 결정 1. 단과 가격 660 vs 550

Aria 추천: **660원 launch → 5주간 모집 진행률 monitoring → 부진 시 얼리버드 550원 전환**.

- 660: 순익 최대화 (Baseline B +870만원). 브랜드 프리미엄 유지. v1.2 800원 대비 -17.5% 인하로 진입장벽 완화.
- 550: 모집 최대화. 순익 -200만원 감소 (Baseline B 기준). 저가 브랜드 인식 risk.

**Tradeoff 정렬**
| 항목 | 660 | 550 |
|---|---|---|
| Baseline B 순익 | +870만원 | +667만원 |
| Baseline B BEP | 16명 | 17명 |
| 모집 예상 (B0056 hypothesis) | 중 | 상 |
| 브랜드 인식 | 프리미엄 | 저가 |
| 얼리버드 여지 | 550까지 인하 여지 有 | 인하 여지 X |

660 은 여지 남기고 학습, 550 은 얼리버드 여지 소진.

### 결정 2. 강사 재협상 확신도

Aria 질문: 5회 flat 250만원 재협상 성공 확률?

- 성공 확률 > 70%: v1.3 성공 시나리오 진행 OK
- 성공 확률 40~70%: fallback 병행 준비. 시나리오 C (44명) 도달 목표로 마케팅 상향
- 성공 확률 < 40%: v1.2 강사료 유지 + 가격 유지 (800원) + 인원 확보 전략 재설계

**Aria 추천**: 성공 확률 상향 위해 **강사에게 총액 유지 + 회차 확대 (5회 → 6회)** 옵션도 제시. 강사 시간 부담은 늘지만 회당 단가 하락 = brand 신호 X (강사 관점).

### 결정 3. 폐강 기준 8명 default 승인?

Aria 추천: **8명 승인**. 근거:
- 세션 인원 6명 미만 = 강사 대비 학생 비율 1:3 이하로 개별 코칭 성격. 강의 형태 X.
- 8명 = tier 하한 (~20명 tier 절반). 강의장 원가 정당화.
- 폐강 시 원가도 절반 감축 (강사 1명 + 세션 1 + 페스티벌 1) → 매출 감소보다 원가 감소가 커서 오히려 순익 개선 케이스 존재 (시나리오 A 폐강 참조).

대안: 10명 (안전권) 또는 5명 (수용 최대).

### 결정 4. 2기 launch 시점 (v1.2 유지)

**2026-08-01 (토) launch, 5주 = 2026-09-05 종강** (v1.2 §6 결정 2 유지).

## 7. Rejected Alternatives (v1.3 신규)

### 대안 A. 단과 660 + 올인원 990,000 (25% off, 15% off 유지)

- Baseline B 매출 = 15×660,000 + 8×660,000 + 5×990,000 = 19,530,000
- 순익 = 19,530,000 - 7,500,000 - 3,368,240 = 8,661,760원 (거의 동일)
- **Rejected**: 올인원 프리미엄 신호 감소. 880,000 flat = 심리적 임계값 (100만원 미만) + 33% off 명확한 마케팅 message.

### 대안 B. 단과 660 + 올인원 1,100,000 (16.7% off)

- Baseline B 매출 = 15×660,000 + 8×660,000 + 5×1,100,000 = 20,080,000
- 순익 = 20,080,000 - 7,500,000 - 3,462,120 = 9,117,880원 (+40만원)
- **Rejected**: 올인원 100만원 초과 = 심리적 저항. 노아 지시 = 880 flat.

### 대안 C. 강사료 회당 200만원 (총 1,000만원/강사)

- 강사 2명 = 2,000만원 → 재협상 성공 대비 -300만원
- Baseline B 660 순익 = 11,703,160원
- **Rejected**: 강사 총 수령 감소 = 재협상 실패 확률 급증. 총액 250만원 유지가 협상 카드.

### 대안 D. 회차 6회 확대 + 강사료 총액 유지 (250만원/강사)

- 강사 회당 = 416,667원
- 학생 부담 = 660 × 1.2 = 792,000원 (5회 660 대비 시간당 유사)
- Baseline B 매출 = 15×792,000 + 8×792,000 + 5×880,000 = 22,616,000
- 순익 = 22,616,000 - 7,500,000 - 3,896,608 = 11,219,392원 (+250만원)
- **Rejected**: 학생 학습 부담 + "5주 완성" 마케팅 message 변경 필요. 결정 2 강사 재협상 옵션으로만 검토.
