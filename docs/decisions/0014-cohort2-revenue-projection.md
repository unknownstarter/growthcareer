## 1. 배경

v1.3 (660 vs 550 subvariant 병기) 검토 후 노아 최종 결정 = **얼리버드 550,000 (선착순 한정) + 이후 일반 660,000** phase 전환 전략. 이 방식은 두 subvariant 병기 대비 다음 장점:

- 초기 모집 가속 (얼리버드 시그널로 신청 앞당김)
- 브랜드 프리미엄 방어 (기본 가격은 660 유지)
- 폐강 risk 감축 (얼리버드 조기 판매로 최소 인원 확보 조기 판단 가능)

강사 재협상은 70% 이상 자신 확보 = 성공 baseline 확정. 폐강 기준은 8명 → 10명 상향 = 안전권 확보.

## 2. 공통 파라미터 (v1.4)

### 강의 구조 (v1.3 유지)

- 회차: 회당 2시간 × 5주 (주 1회) = 5회
- 세션 분리: 단과 A 시간대 + 단과 B 시간대 = 강의장 세션 2개
- 올인원 학생 = 두 세션 모두 참여

### 가격 (v1.4 얼리버드 phase 전략)

| SKU | 얼리버드 (원) | 일반 (원) | 회차 | 시간당 얼리 | 시간당 일반 |
|---|---|---|---|---|---|
| 단과 A | 550,000 | 660,000 | 10h | 55,000 | 66,000 |
| 단과 B | 550,000 | 660,000 | 10h | 55,000 | 66,000 |
| 올인원 | 880,000 (flat) | 880,000 (flat) | 20h | 44,000 | 44,000 |

**얼리버드 정책** (v1.5 확정, 2026-07-06):
- **기간 기반** (인원 기반 X): **모집 시작 후 1주일간** 얼리버드 가격 적용
- 예: 모집 시작 7/14 → 얼리버드 종료 7/20 (일) → 7/21 부터 정가 660,000
- 예상 접수율 30% (마케팅 가정) — Baseline B 순익 = **+812만원**
- 대표 이유: 인원 기반 배분은 초반 접수 안 되면 마감 시점 예측 불가. 기간 기반 = 명확한 마감일 + 마케팅 카운트다운 소재.
- 올인원 은 얼리버드 개념 X (880,000 flat, 단과 얼리 대비 이미 20% off)
- 얼리버드 마감 후 일반 가격 전환 (자동 공지)

### 강사료 (v1.4 재협상 성공 확정)

- 5회 flat 2,500,000원/강사 (회당 500,000원)
- 사업자 세금계산서 발행 → 청구액 2,750,000원 (2,500,000 + VAT 250,000)
- 노아 매입 공제 250,000원 → 실 부담 2,500,000원/강사
- 강사 2명 = **5,000,000원 total**

### 강의장 (v1.3 유지)

| 인원 tier | 시간당 (원) | 회당 (2h) | 5회 총액 (원) |
|---|---|---|---|
| ~20명 | 100,000 | 200,000 | 1,000,000 |
| 21~30명 | 150,000 | 300,000 | 1,500,000 |
| 31~40명 | 200,000 | 400,000 | 2,000,000 |

### 페스티벌 티켓

- 2 × 250,000 = **500,000원** (교육 원가 계층)

### Cowork 커미션

- 매출 × 40% × 12% = 매출 × 4.8%

### 마케팅

- 매출 × 5%

### 부가세 실납부

- 매출 부가세 = 매출 × 10%
- 매입 부가세: 강사 500,000 (250만 × 10% × 2강사)
- 강의장 매입 공제 X 가정

### 폐강 기준 (v1.4 상향)

- **세션별 인원 10명 미만 → 폐강 + 환급**

## 3. 시나리오 A~D 재계산 (얼리버드 50% mix, 재협상 성공)

### 시나리오 A. 비관 14명 (8+4+2) → 세션 B 폐강 확정

세션 A 인원 = 단과 A 8명 + 올인원 2명 = 10명 (~20 tier 유지, 세션 A 만 진행)
세션 B 인원 = 단과 B 4명 + 올인원 2명 = 6명 < 10명 = **폐강**

**폐강 처리**:
- 단과 B 4명 전액 환급
- 올인원 2명 = 세션 A 만 참여 = 단과 A 상당 가격으로 조정 (얼리 550 또는 일반 660 원)

**매출 (얼리 50% mix)**
- 단과 A 8명 = 얼리 4 × 550,000 + 일반 4 × 660,000 = 2,200,000 + 2,640,000 = 4,840,000
- 올인원 2명 (세션 A 만) = 얼리 1 × 550,000 + 일반 1 × 660,000 = 1,210,000
- 총 = **6,050,000원**

**교육 원가 (세션 A 만)**
- 강사 1명: 2,500,000
- 강의장 세션 A 1개 (~20 tier): 1,000,000
- 페스티벌: 세션 A 참여 학생 1명 분 (2×250,000 중 절반) 가정 = 250,000
- 소계 = **3,750,000원**

**간접 원가**
- Cowork: 6,050,000 × 4.8% = 290,400
- 마케팅: 6,050,000 × 5% = 302,500
- 부가세: 605,000 - 250,000 (강사 1명 매입) = 355,000
- 소계 = **947,900원**

**순익 = 6,050,000 - 3,750,000 - 947,900 = +1,352,100원 (흑자 135만원)**

폐강 정책이 원가 절반 감축으로 방어. v1.3 폐강 케이스 (+82만원 550 / +179만원 660) 대비 mix 로 중간값 도출.

## 6. 노아 최종 결정 확정 요약 (2026-07-06)

### ✅ 결정 1. 가격 전략 확정

**얼리버드 550,000 (선착순) → 이후 일반 660,000 phase 전환**.

- 두 subvariant 병기 대비 우수한 이유: 모집 가속 + 브랜드 프리미엄 방어 + 폐강 risk 조기 판단
- 얼리버드 = 2기 한정 (3기 여부 공지 X)

### ✅ 결정 2. 강사 재협상 확정

**70% 이상 자신 = 재협상 성공 baseline 확정**.

- 5회 flat 2,500,000원/강사 = 회당 500,000원
- 계약서 signature 확보 후 진행. Fallback 준비 병행

### ✅ 결정 3. 폐강 기준 10명 상향

**세션별 인원 10명 미만 → 폐강 + 환급**.

- v1.3 8명 대비 안전권 확보
- 시나리오 A (14명) 은 세션 B 자동 폐강 = 원가 절반 감축으로 순익 방어

### ✅ 결정 4. Launch 2026-08-01 (토) 확정

**5주 = 2026-09-05 종강**. v1.3 유지.

### 🔲 결정 5. 얼리버드 배분 비율 (Aria 제안, 노아 확인 필요)

Aria default: **각 단과 정원의 50%**.

**Tradeoff 정렬**

| 배분 | 모집 가속 | 순익 (Baseline B) | 브랜드 |
|---|---|---|---|
| 30% (보수) | 저 | +8,120,000 (얼리 소진 후 일반 phase 김) | 프리미엄 방어 강 |
| **50% (Aria default)** | 중 | +7,732,740 | 중립 |
| 70% (공격) | 상 | +7,345,480 | 저가 인식 risk |
| 100% (얼리 만) | 상 | +6,674,100 (v1.3 550 flat 과 동일) | 저가 인식 확정 |

**Aria 추천 = 50%**: 모집 가속 + 순익 유지 + 브랜드 균형. 얼리 소진 시 일반 phase 도달로 브랜드 신호도 유지.

**노아 확인 필요**: 50% default 승인 or 다른 % 지시.

## 7. Rejected Alternatives (v1.4 신규)

### 대안 A. 얼리버드 100% (얼리 만 판매, 일반 phase 없음)

- Baseline B 매출 = 15×550,000 + 8×550,000 + 5×880,000 = 16,650,000 (v1.3 550 flat 과 유사)
- 순익 ≈ +6,674,100 (v1.3 550 flat)
- **Rejected**: 브랜드 저가 인식 확정. 일반 phase 없으면 얼리버드 의미 상실 (그냥 550 flat)

### 대안 B. 얼리버드 = 시간 한정 (기간 한정, 인원 X)

- Launch 후 2주간 얼리 550, 이후 일반 660
- 문제: 2주간 매출 예측 어려움. 마감 신호 애매 (인원 = 명확, 시간 = 애매)
- **Rejected**: 노아 결정 = 선착순 인원 기준으로 명확

### 대안 C. 얼리버드 x 폐강 조기 판단 tie-in

- 얼리 50% 소진 시점 = launch + 2주 = 폐강 조기 판단 시점
- 얼리 소진 진행률 < 30% = 폐강 조기 예고 (2주 시점)
- **Adopted (implicit)**: R3 리스크 완화안으로 통합. 별도 결정 X.

### 대안 D. 올인원에도 얼리버드 적용 (얼리 750, 일반 880)

- Baseline B 매출 = 얼리 mix + 올인원 얼리 3 × 750,000 + 일반 2 × 880,000 = 2,250,000 + 1,760,000 = 4,010,000
- 총 = 18,370,000 - 4,400,000 + 4,010,000 = 17,980,000 → 순익 -30만원
- **Rejected**: 올인원 은 이미 단과 얼리 대비 20% off. 추가 얼리 = 원가 회수 어려움 + 마케팅 message 혼란
