## 1. 사용 디자인 토큰 (변경 X, 참고용)

### 컬러
- `bg` (다크 배경) / `surface` (살짝 밝은 다크) / `fg` / `fg-muted` / `fg-subtle` / `border`
- 브랜드 5색: `brand-indigo` / `brand-violet` / `brand-purple` / `brand-pink` / `brand-fuchsia`
- 규칙: 솔리드 블록만 사용. 그라데이션·블렌딩 금지.

### 타이포 (Pretendard Variable 900 Black 기준)
- `text-display-2xl` (clamp 6rem~20rem) — 거대 단일 임팩트
- `text-display-xl` (clamp 4rem~12rem) — Hero급
- `text-display-lg` — 섹션 헤드라인
- `text-display-md` / `sm` — 보조 헤드라인
- Letter-spacing: -0.04em~-0.05em (헤드라인), 0.2em~0.4em (eyebrow uppercase)
- Line-height: 0.95~1.05 (헤드라인), 1.4~1.6 (본문)

### Spacing
- 섹션 간 패딩: `py-24 sm:py-28 lg:py-32`
- Container: max-w-7xl
- 카드 패딩: `p-8 sm:p-10`

## 2. 섹션별 UI 명세 (7섹션)

### Sec 01. Problem

**단일 목표**: "내 얘기다" 인식 → 해결 갈증 점화

**컴포넌트 트리**:
```
<Section tone="bg" id="problem">
  <Container>
    <Eyebrow n="01">Problem</Eyebrow>
    <BigStat value="..." label="..." />     ← 거대 단일 통계
    <Divider />
    <PainList items={3} />                   ← 1줄짜리 페인 3개
  </Container>
</Section>
```

**ASCII 와이어프레임**:
```
┌──────────────────────────────────────────┐
│ 01 · PROBLEM                              │
│                                            │
│  ████████████ 거대 KPI 숫자 ████████████   │ ← text-display-2xl, text-brand-pink
│  통계 라벨 한 줄                            │ ← text-fg-subtle text-sm uppercase
│                                            │
│  ─────────────── divider ───────────────  │
│                                            │
│  · 비자가 막는 진입 장벽                    │
│  · 한국어 인터뷰의 벽                       │
│  · 업계 네트워크 0                          │
└──────────────────────────────────────────┘
```

**디자인 임팩트**: 한 번에 한 가지 정서 (고립감). 통계 1개 + 페인 3개. *현재 Problem 의 3카드 그리드* 를 *거대 KPI + 1열 페인* 으로 압축.

### Sec 02. Value 🎯 시각 결정 필요

**단일 목표**: 4주 후 손에 잡히는 *결과물* 명시 (Solution + ValueCards + Outcome 통합)

**옵션 A — 3장 솔리드 블록 카드** (기본 권장)
```
┌────────────┬────────────┬────────────┐
│  INDIGO    │   VIOLET   │    PINK    │
│            │            │             │
│  결과물 1  │  결과물 2  │  결과물 3   │ ← 카드당 큰 키워드 1개
│  (한 줄)   │  (한 줄)   │  (한 줄)    │
│            │            │             │
│  보조 카피 │  보조 카피 │  보조 카피  │
└────────────┴────────────┴────────────┘
```
임팩트: 솔리드 컬러 블록 3개 = 시각 강함. 모바일에서 세로 스택.

**옵션 B — 1열 큰 카드 (스토리텔링)**
```
┌──────────────────────────────────────────┐
│  결과물 1 — 한 줄 임팩트                  │ ← 가로 풀블리드
│  보조 카피 + 메타 (소요시간·산출물)        │
└──────────────────────────────────────────┘
┌──────────────────────────────────────────┐
│  결과물 2 — 한 줄 임팩트                  │
│  보조 카피                                 │
└──────────────────────────────────────────┘
┌──────────────────────────────────────────┐
│  결과물 3 — 한 줄 임팩트                  │
│  보조 카피                                 │
└──────────────────────────────────────────┘
```
임팩트: 스토리 흐름. 길지만 깊이 있음.

**옵션 C — 2x2 그리드 + 메인 카드**
```
┌──────────────────────┬──────────────┐
│                       │   결과물 2    │
│   메인 결과물 1       ├──────────────┤
│   (큰 카드)           │   결과물 3    │
│                       ├──────────────┤
│                       │   결과물 4    │
└──────────────────────┴──────────────┘
```
임팩트: 1순위 결과물에 시각 무게 집중. 단 4개 결과물 필요.

### Sec 03. Mentor 🎯 시각 결정 필요

**단일 목표**: "현직 인사이더가 1:1 로 붙는다" 신뢰 확보 (+ Bonus 1:1 멘토 흡수)

**옵션 A — 현재 풀 카드 3개 유지**
```
┌──────────────────────────────────────┐
│ [강사 사진]                            │
│ 이름 · 소속                            │
│ 경력 그룹 1                            │
│ 경력 그룹 2                            │
│ 경력 그룹 3                            │
└──────────────────────────────────────┘
× 3 강사
```
임팩트: 정보 풀공개. 단 길이 길어짐.

**옵션 B — 인용 중심 압축** (권장)
```
┌──────────────────────────────────────┐
│  [강사 1 흑백 사진]                    │ ← 좌측 풀블리드
│                                        │
│         " 권위 인용 한 줄 "             │ ← text-display-md fuchsia
│         — 이름 · 한 줄 소속              │
│                                        │
│         핵심 경력 3개만 칩 형태          │
└──────────────────────────────────────┘
× 3 강사 (세로 스택)
```
임팩트: 한 명당 한 화면. 권위 한 줄 + 사진 = 강력. 디테일은 토글 또는 "약력 보기" 링크.

**옵션 C — 탭 전환**
```
┌──────────────────────────────────────┐
│ [박성철] [이제향] [Nino]    ← 탭        │
├──────────────────────────────────────┤
│  선택된 강사 풀 카드 (옵션 A 형태)      │
└──────────────────────────────────────┘
```
임팩트: 정보 밀도 높지만 한 명만 보임. 모바일에서 탭 UX 까다로움.

### Sec 04. Program

**단일 목표**: 4주 동안 *뭘* 하는지 구체 (+ Bonus 면접·포트폴리오 흡수)

**컴포넌트 트리**:
```
<Section tone="bg" id="program">
  <Container>
    <Eyebrow n="04">Program</Eyebrow>
    <SectionHead headline="..." />
    <Timeline rows={4}>
      <Week n="1" deliverable="..." />
      <Week n="2" deliverable="..." />
      <Week n="3" deliverable="..." />
      <Week n="4" deliverable="..." accent="pink" />  ← 마지막 주만 강조
    </Timeline>
  </Container>
</Section>
```

**ASCII 와이어프레임**:
```
┌──────────────────────────────────────────┐
│ 04 · PROGRAM                              │
│                                            │
│  헤드라인 (text-display-lg)                │
│                                            │
│  ┌────┬───────────────────────────┐       │
│  │ W1 │ 산출물 1 · 산출물 2          │ violet bar
│  ├────┼───────────────────────────┤       │
│  │ W2 │ 산출물 3 · 산출물 4          │       │
│  ├────┼───────────────────────────┤       │
│  │ W3 │ 산출물 5 · 산출물 6          │       │
│  ├────┼───────────────────────────┤       │
│  │ W4 │ ★ 최종 산출물 — 핑크 강조    │ pink bar
│  └────┴───────────────────────────┘       │
└──────────────────────────────────────────┘
```

**디자인 임팩트**: 좌측 주차 라벨 + 우측 산출물. 누적감. 마지막 주 핑크 = 클라이맥스.

### Sec 05. Eligibility & Schedule

**단일 목표**: "내가 자격 되나 + 언제인가" 마찰 제거 + 시간 압박 주입

**컴포넌트 트리** (split-screen):
```
<Section tone="violet" id="eligibility">
  <Container>
    <Eyebrow n="05">Eligibility</Eyebrow>
    <SplitGrid>
      <Left>
        <ChecklistCard items={[
          "한국 거주",
          "외국 국적",
          "D-2/D-4/D-10/E-시리즈",
          "한국어 강의 OK"
        ]} />
      </Left>
      <Right>
        <Countdown to="2026-06-14T23:59" />
        <CapacityBar current={N} total={30} />
      </Right>
    </SplitGrid>
  </Container>
</Section>
```

**ASCII 와이어프레임**:
```
┌──────────────────────┬──────────────────┐
│ 자격 체크리스트       │ 마감까지          │
│                       │                    │
│ ☑ 한국 거주           │  ██ ██ : ██ : ██  │ ← 거대 카운트다운
│ ☑ 외국 국적           │   일   시  분  초  │
│ ☑ D-2/D-4/D-10/E     │                    │
│ ☑ 한국어 강의 OK      │  ━━━━━━━━━━━━     │ ← 진행바
│                       │  N / 30 마감       │
│ → 모두 ☑ 면           │                    │
│   '지금 신청' CTA     │                    │
└──────────────────────┴──────────────────┘
```

**디자인 임팩트**: violet 풀블리드 배경. 좌측 indigo 체크 / 우측 pink 카운트다운. 자격 통과 시 즉시 CTA.

### Sec 06. Pricing & Guarantees 🎯 시각 결정 필요

**단일 목표**: 가격 + 보장 동시 → 리스크 제거 → CTA 임계점 (+ Bonus 비자 가이드 흡수)

**옵션 A — Split-screen (좌 가격 / 우 보장)**
```
┌──────────────────────┬──────────────────┐
│  VIOLET 블록          │  PURPLE 블록     │
│                       │                    │
│  s/1,100,000원/       │  ✓ 7일 이내 100%  │
│  ████████             │    환불 보장       │
│  880,000원            │                    │
│  (거대)               │  ✓ 20명 미달 시   │
│                       │    전액 환불 +    │
│  VAT 포함             │    재모집          │
│  계좌이체             │                    │
│                       │  ✓ 비자 가이드     │
│  [ 지금 신청 → ]      │    제공            │

```
임팩트: 가격 충격 ↔ 보장 진정 동시 시야. 1화면.

**옵션 B — 스택형 단일 컬럼**

│  s/1,100,000원/                            │

임팩트: 가격 카드만 시선 집중. 보장은 신뢰 신호 한 줄.

## 4. Preview 라우트 시안 비교 대상

Phase 3 에서 다음 3섹션의 옵션 카드들을 `/preview/section-restructure` 에 렌더:

| 섹션 | 시안 옵션 |
|---|---|
| Value | A (3장 솔리드) / B (1열 스토리) / C (2x2 그리드) |

각 시안 카드 하단에 `[이걸 골랐어]` 버튼:
- `navigator.clipboard.writeText("[picked] Value: 옵션-B")` 같은 형태로 픽 자동 복사
- Toast: "복사됨 — 채팅에 paste 해서 결정 전달"

## 5. 도메인 데이터 가드 (정책 정정 미반영 명시)

- preview 라우트의 시안은 `domain/program.ts` / `domain/faq.ts` 의 *현재* 데이터를 그대로 import 해서 렌더
- ⚠ *공연 참여 = 우수자만* 정책 정정은 **카피 작업 차수에서 별도 반영**. preview 카피에는 *현 상태 (수료자 전원)* 가 그대로 나오는데, 이는 *시안 비교 목적의 임시 상태* 임을 시안 페이지 상단에 명시
