## 5. 모집 페이지 flow

### 기존 vs 신규

- 기존 `/fan-to-pro` 는 1기 랜딩 (다크). §7.4 라이브 페이지 = 신중 접근.
- 옵션 A: 기존 페이지 8/1 launch 후 부분 변경 (2기 카피로 덮음).
- 옵션 B: 별도 신규 페이지 (예: `/fan-to-pro/cohort-2` 또는 `/programs/2026-fall`) 신설 + 기존 페이지는 1기 archive 링크로 유지.

**Aria 추천 = 옵션 B**: 신규 페이지. 근거:
- 기존 1기 페이지 = 마케팅 자료 소재로 계속 활용 가능 (past cohort proof)
- 신규 페이지에서 course/bundle 선택 UI + 얼리버드 카운트다운 실험 가능
- 8/1 launch 직전 URL swap (redirect) 로 SEO 손실 방지
- 노아 확인 필요 = Q6

### course/bundle 확장 = Iris Slice 2c 대기

- 신청 폼 = 단과 A / 단과 B / 올인원 3택 셀렉터
- Server action `submit-application` 시그니처 = ADR 0013 결정 3 (기존 유지 + course_id / bundle_id nullable 추가)
- 결제 amount 자동 계산 = 얼리버드 phase 판정 (server-side timestamp)

## 6. 폐강 정책 (v1.5 확정)

- **세션별 인원 10명 미만 -> 폐강 + 환급**.
- 폐강 조기 판단 시점 = 얼리버드 마감 (7/20 자정) 시점의 진행률.
  - 얼리 quota 30% 미달 = 폐강 조기 예고 (marketing 신호)
  - 얼리 quota 50% 이상 = 정상 진행 확신
- 폐강 확정 통보 = 모집 마감 (7/31) 다음 날 (8/1 오전).
- 폐강 환급 프로세스 = 기존 환급 정책 재사용 (ADR 0003 참조).

## 7. 강사 재계약 or 신규 섭외

### 단과 A (Fan to Pro)

- 1기 강사 8명 (수료식 파트, 각 회차별 게스트 등) 중 2기 재계약 대상 판단 필요.
- 재계약 조건 = 5회 flat 2,500,000원 (ADR 0014 v1.5 확정, 회당 500,000원).
- 노아 70% 이상 자신 = 재협상 성공 baseline.
- **노아 확인 필요 = Q1** (재계약 vs 신규 섭외).

### 단과 B (셰르파 뮤직)

- 셰르파 뮤직 대표 신규 계약 필요.
- 계약서 초안 = ADR 0014 v1.5 조건 반영 (5회 flat 2,500,000원, VAT 별도, 세금계산서).
- 기존 계약서 template = `docs/contracts/instructor-agreement.md` 재사용 + 셰르파 정보로 정정.
- **노아 확인 필요 = Q2** (계약서 초안 작성 승인).

## 8. 마케팅 계획

### Cowork 유지

- 매출 x 40% x 12% = 매출 x 4.8% commission (ADR 0014 v1.5 반영).
- 파트너십 관계 유지 (기존 계약 자동 연장 or 재계약 확인 필요).

### 재제작

- 인스타 카드뉴스 10종 재제작 (2기 얼리버드 550 + 정가 660 + 올인원 880 카피).
- 얼리버드 카운트다운 소재 (배너 + SVG + PNG) 신규 발주.
- SEO/GEO 대응 = 기존 B0019 인프라 재사용 (JSON-LD 5종 + OG locale + llms.txt).

### 예산

- 마케팅 = 매출 x 5% (ADR 0014 v1.5).
- **노아 확인 필요 = Q3** (마케팅 예산 규모, Baseline B 기준 약 92만원).
