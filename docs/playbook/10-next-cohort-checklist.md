# 10 Next Cohort Checklist — 다음 기수 운영 전 점검

> 2기 (또는 그 이후) 모집 시작 전 / 강의 시작 전 / 강의 진행 중 체크리스트.
>
> 1기 운영 끝나면 회고 + 본 체크리스트 갱신.

---

## Phase A — 다음 기수 모집 시작 D-4주

### 1. 일정 결정

- [ ] 1기 완전 종료 (수료식 7/25 + 후속 응대 1주)
- [ ] 2기 강의 시작일 결정 (1기 종료 후 최소 2주 텀)
- [ ] 2기 모집 시작일 결정 (강의 시작 D-4주)
- [ ] 2기 모집 마감일 결정 (강의 시작 D-1주)
- [ ] 강의 회차 일정 결정 (8회 회차 × 토 + 일)
- [ ] 강의장 예약 (블루스프링하우스 또는 다른 장소)
- [ ] 수료식 일정 결정

### 2. 가격 / 정원 결정

- [ ] 가격 결정 (1기 880,000원 → 동일 / 인상 / 인하)
- [ ] 정원 결정 (1기 30명 / 최소 8명)
- [ ] 친구 추천 보상 정책 유지 / 변경 (5만원 비과세 한도)
- [ ] 동문 추천 보상 정책 도입 여부 (F9 백로그)

### 3. 강사 섭외

- [ ] 1기 강사 재계약 의사 확인 (3인)
- [ ] 신규 강사 섭외 필요 시 DEEPI 측에 요청
- [ ] 강사 회차 매핑 결정
- [ ] 강사 계약서 갱신 (`docs/contracts/instructor-agreement.md`)
- [ ] 강사 회사 정보 확인 (회사명 / 사업자번호 / 부가세 발행 여부 / 계좌)

### 4. 코드 / 데이터 사전 작업

- [ ] `cohorts` 테이블에 2기 row INSERT (program_id + slug + starts_on + ends_on + capacity + min_to_open + status='open' + accepts_signup_now=true)
- [ ] `sessions` 테이블에 2기 8회차 row INSERT
- [ ] `program.ts` 의 `ENROLLMENT_CAP.cutoffAt` 갱신 (2기 마감 datetime)
- [ ] `program.ts` 의 `SCHEDULE` 갱신 (2기 일정 / 회차 라벨)
- [ ] 마케팅 카피 갱신 (Hero / Pricing / Recruitment 의 일정 / 가격)
- [ ] 강사 카드 / 사진 갱신 (변경 시)
- [ ] FAQ 갱신 (1기 운영 중 받은 질문 추가)
- [ ] Testimonials 갱신 (1기 후기로 교체)
- [ ] SocialProof 수치 갱신 (수료생 수 / 만족도)

### 5. 자동화 / 기능 작업 (8장 + 9장 기반)

- [ ] **F4 (UI 자동 재활성화)** — 2기 모집 시작 시 즉시 활성화 (1일)
- [ ] **A3 (다음 기수 알림 일괄 이메일)** — 1기 next_cohort_interest 신청자에게 발송 준비 (1일)
- [ ] **A1 (paymentConfirmed 자동 발송)** — 2~3일
- [ ] **A2 (리마인드 자동 발송)** — 2일
- [ ] **A6 (회계 CSV 자동 발송)** — 1일
- [ ] **F3 (수료증 자동 발급)** — 1기 수료식 전 가능하면 적용 (2일)

총 작업량: 10~15일

## Phase B — 모집 시작 D-1주

### 사전 점검

- [ ] 사이트 모든 카피 (한/영) 검수
- [ ] 모집 마감 cutoff datetime 정확히 박힘 (Vercel env / DB / program.ts)
- [ ] `force-dynamic` 또는 ISR revalidate 적용 확인 (SSG cache 사고 방지)
- [ ] 마케팅 자산 준비 (카드뉴스 / 배너 / 원페이저 PDF — 2기 버전)
- [ ] 자동 발송 시스템 테스트 (자체 신청 → 자동 paymentGuide → 자동 paymentConfirmed)
- [ ] 카톡 채널 응대 준비 (외출 일정 / 휴가 계획)

### 알림 리스트 일괄 발송

- [ ] `applicants` 의 `status='next_cohort_interest'` row 확인
- [ ] `consent_marketing=true` 필터 (옵트인 검증)
- [ ] nextCohortAnnouncement template 작성
- [ ] 일괄 이메일 BCC 발송
- [ ] 발송 후 `status='notified'` 로 변경 (수동 또는 자동)

### Cowork 파트너십 갱신

- [ ] DEEPI 측 카드뉴스 / 광고 자산 협업
- [ ] 유니온 픽처스 측 공연 일정 협업 (수료생 동행 가능 공연 확인)

## Phase C — 모집 시작 후

### 일일 운영 (1기 동일)

- [ ] 아침 (08:00 ~ 10:00) — 신규 신청 chip 확인 → 자동 paymentGuide 발송 확인 → 누락 시 수동
- [ ] 오후 (14:00 ~ 18:00) — 토스뱅크 입금 알림 → 자동 매칭 (A5 구현 시) 또는 수동 paid 토글
- [ ] 저녁 (20:00 ~ 22:00) — reminder 자동 발송 확인 (A2 구현 시) 또는 수동
- [ ] 야간 (22:00 ~ 24:00) — 외국인 학생 카톡 채널 응대 (시차 응대)

### 진행 중 점검

- [ ] 매주 paid 인원 vs 목표 비교 (예: 주당 5명 목표 → 4주 20명)
- [ ] 신청 funnel 분석 (GA4) — 어느 섹션에서 이탈 많은지
- [ ] 채널별 신청자 비율 (Reddit / FB / 인스타 / Cowork / 친구 추천)
- [ ] 약점 채널 보강 (마지막 2주 가속화)

## Phase D — 모집 마감 후 + 강의 시작 전

- [ ] 마감 사이트 자동 전환 확인 (Hero / Pricing / StickyCTA / ApplyForm)
- [ ] paid 인원 확정 (폐강 기준 8명 이상)
- [ ] cohortKickoff 메시지 발송 (강의장 + 시간 + 카톡 + 준비물 + 일정 + 원페이저 PDF)
- [ ] 카카오톡 오픈채팅 생성 + paid 학생 입장 안내
- [ ] 학생 LMS 계정 invite (must_change_password) — 강사 surface 준비 됐다면 강사도
- [ ] 원페이저 PDF 갱신 (2기 일정 / 강사 / 가격) + Google Drive 업로드 + 링크 메시지에 paste
- [ ] 강의장 예약 최종 확인 + 결제
- [ ] 강사 자료 PDF 사전 수령
- [ ] 출석부 + 명찰 (선택) 준비
- [ ] 다과 / 음료 결정 + 결제
