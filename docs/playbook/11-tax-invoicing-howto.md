## 0. 들어가기 전 — 세 가지 절대 헷갈리지 말 것

| 구분 | 누구 ↔ 누구 | 처리 | 신고 시점 |
|---|---|---|---|
| **세금계산서** | 사업자 ↔ 사업자 | VAT 10% 추가해서 송금 / 송금 받기 | 부가세 분기 신고 (매입/매출 합산) |
| **원천징수** | 사업자 ↔ 개인 (사업소득) | 3.3% (소득세 3% + 지방세 0.3%) 차감 후 송금 | 매월 10일 (전월분) |
| **현금영수증** | 사업자 ↔ 개인 (소비) | 발행만 (별도 차감 X) | 홈택스 자동 누적 |

**핵심 판별 질문**: "거래 상대방이 **사업자번호** 가지고 있는가?"
- YES → 세금계산서 (양방향)
- NO + 사업소득 (강사 등) → 원천징수
- NO + 소비 (학생) → 현금영수증

## 1. 강사료 처리

### 분기

```
강사가 사업자 (개인사업자 OR 법인) ?
  ├─ YES (사업자번호 보유)
  │   → 강사 회사가 Dropdown 에 세금계산서 발행
  │     (강의료 + VAT 10%)
  │   → Dropdown 송금 (강의료 + VAT)
  │   → Dropdown 매입 VAT 차감 (부가세 신고)
  │
  └─ NO (개인, 프리랜서)
      → Dropdown 이 3.3% 원천징수 후 송금
        (강의료 × 0.967)
      → 매월 10일 홈택스 원천세 신고
      → 매년 2월 강사에게 원천징수영수증 발행 (지급명세서)
```

원천징수 (사업자 X 시 3.3% 차감) 도 가능합니다. 편하신 방식 알려주세요.

### 강사 회사 (사업자 O) 케이스 — 세금계산서 받기

1. 강사 회사가 **홈택스** (https://hometax.go.kr) 에서 전자세금계산서 발행
   - 공급자 = 강사 회사
   - 공급받는자 = Dropdown (154-28-02110)
   - 품목 = "강의료 (Fan to Pro 1기 N회차)" 등
   - 공급가액 = 강의료, 세액 = 강의료 × 10%, 합계 = 강의료 × 1.1
2. Dropdown 의 hello@dropdown.xyz 로 발행 알림 자동 발송
3. Dropdown 이 홈택스 로그인해서 수신 확인 (또는 알림 메일 확인)
4. 송금 (강의료 + VAT)
5. 분기 부가세 신고 시 매입 VAT 차감

### 강사 개인 (사업자 X) 케이스 — 원천징수

1. 강의료 결정 (예: 500,000원)
2. Dropdown 이 3.3% 차감 → 483,500원 송금
3. 매월 10일까지 홈택스 **"원천세 신고"** 메뉴에서 전월분 신고
   - 신고 항목: "사업소득" (인적용역)
   - 강사 주민번호 (또는 외국인등록번호) + 사업소득 지급액 + 원천징수 세액
4. 신고 후 원천징수 세액 16,500원 (= 500,000 × 0.033) Dropdown 이 국세청에 납부
5. 매년 2월 (전년도분 종합) → 강사에게 **지급명세서** 발행 (강사가 5월 종소세 신고 시 활용)

> **외국인 강사** 의 경우: 거주자 / 비거주자 구분 필요. 거주자 = 한국 거주 183일+, 일반 원천징수와 동일. 비거주자 = 22% 원천징수 (조세조약 따라 다름). 1기는 한국 거주자 가정.

## 2. Cowork (DEEPI) 12% 마케팅 수수료 처리

### 약정 (확인 필요)

- 결제 인원당 수강료 12%
- 현재 계산: 10명 × 880,000 × 12% = **1,056,000원**
- 산정 기준 (VAT 포함 vs 별도) — **약정 확인 필요**
- 환불자 차감 여부 — **약정 확인 필요**
- 정산 시점 (월별 vs cohort 종료 후) — **약정 확인 필요**

### 처리 (Cowork = 사업자 가정)

DEEPI = 법인 사업자 (유니온 픽처스 자회사). 세금계산서 발행 의무.

1. DEEPI 가 Dropdown 에게 세금계산서 발행
   - 공급자 = DEEPI
   - 공급받는자 = Dropdown (154-28-02110)
   - 품목 = "Fan to Pro 1기 마케팅 수수료"
   - 공급가액 = 1,056,000원 (또는 약정에 따라 다름)
   - 세액 = 10% (약정이 VAT 별도 면)
2. Dropdown 송금
3. Dropdown 부가세 신고 시 매입 VAT 차감

### 확인할 정보 (DEEPI 측에 요청)

```
안녕하세요 DEEPI 측 담당자님 :)

Fan to Pro 1기 마케팅 수수료 정산 준비 위해 정보 부탁드려요.

1. 사업자번호 + 회사명 (유니온 픽처스 자회사이지만 별도 사업자 가정)
2. 담당자 이메일 (세금계산서 발행처)
3. 송금 받으실 계좌 (은행 / 계좌번호 / 예금주)
4. 12% 산정 약정 재확인:
   - VAT 포함 880,000 기준 (= 105,600/인) 또는 VAT 제외 800,000 기준 (= 96,000/인)?
   - 환불자 차감 여부?
   - 정산 시점 (월별 / cohort 종료 후) ?
5. 세금계산서는 Dropdown 사업자번호 154-28-02110 으로 발행 부탁드려요.
```

## 4. 네트워킹 파티 (7/25) — 식음료 / 케이터링

식음료 회사가 사업자면 세금계산서. 작은 식당 / 카페면 카드매출전표.

- 큰 금액 (50만원+) = 세금계산서 권장 → 부가세 매입 차감 가능
- 작은 금액 = 카드 결제 후 매출전표 (= 영수증) 보관 → 비용 처리 가능 (VAT 차감은 사업자 카드만)

## 5. 학생 측 매출 처리

### 매출 인식

- **학원 미등록 = VAT 10% 의무** (시나리오 B). 면세 적용 X.
- 880,000원 = 800,000 (매출 본체) + 80,000 (매출 VAT)
- 매 결제 시점에 매출 + VAT 분리 기장

### 학생에게 영수증 / 증빙 발행

대부분 학생 = 개인 소비자. 세금계산서 의무 X. 발행 선택지:

1. **현금영수증** (default, 권장) — B0023 시스템 이미 구축. 학생 전화번호 입력 시 자동 발행. 홈택스 자동 누적.
2. **세금계산서** (예외) — 학생이 회사 지원 받아 사업자번호 제공 시. 학생 / 회사로부터 사업자번호 + 회사명 + 담당자 이메일 받아서 홈택스 발행.
3. **간이영수증** (예외) — 학생이 종이 영수증 요청 시. 거의 없음.

### 학생 회사 지원 케이스 (있을 시)

운영자 처리:
1. 학생이 회사 사업자번호 + 회사명 제공
2. Dropdown 홈택스 로그인 → 세금계산서 발행
3. 공급자 = Dropdown, 공급받는자 = 학생 회사
4. 발행 후 학생 / 회사 이메일로 자동 발송

## 6. 도구 — 홈택스 vs SaaS

### 홈택스 (https://hometax.go.kr)

- **공식 + 무료**
- 전자세금계산서 발행 / 수신 / 원천세 신고 / 부가세 신고 / 종소세 신고 모두 가능
- 로그인: 공동인증서 (구 공인인증서) 또는 간편인증 (네이버 / 카카오 / 토스 등 — 사업자도 일부 가능)
- 1인 사업자 (Dropdown) 에 충분
- 단점: UI 구식, 매월 / 매분기 직접 들어가야 함

### SaaS (참고만, 1기 도입 X)

- **더존 (Smart A / Bizon)** — 중소기업 표준. 강사 / 운영 다수 시 검토.
- **컴스토리 / 헬로우스토리** — 1인 사업자 친화. 월 1~2만원.
- **알밤 / 영수증.com** — 영수증 / 카드매출전표 통합 관리.

1기 = 홈택스 + 카카오 채널 / 이메일 응대로 충분. 100명+ (3기+) 시 SaaS 검토.

## 9. 자주 헷갈리는 케이스 + 답

### Q1. 강사가 외국인 (D-10 등 한국 거주) 인데 사업자 X 면?

→ 한국 거주자 (183일+) → 거주자 원천징수 (3.3%). 외국인등록번호로 신고.
→ 비거주자 (183일 미만) → 22% 원천징수 (조세조약에 따라 감면 가능).
→ 1기는 한국 거주 가정. 비거주자 강사 발생 시 별도 ADR.

### Q2. Cowork 가 12% 수수료를 VAT 포함 880,000 기준으로 청구할지 별도 800,000 기준일지?

→ **약정 확인 필요**. 일반 관행: 거래 금액 (= VAT 포함 880,000) 기준. 그러나 명시적 약정이 우선.
→ 명시 없으면: Cowork 측 인보이스가 VAT 별도 / VAT 포함 표기 확인.

### Q3. 환불 학생 (1명) 의 Cowork 수수료는 차감?

→ **약정 확인 필요**. 일반 관행: 환불자도 청구 (Cowork 가 마케팅 활동은 이미 함). 단 운영자 협상 시 차감 가능.

### Q4. 강의 시작 전에 강사료 일부 선지급 가능?

→ 가능. 단 사업자 강사면 사전 세금계산서 발행 받고 송금. 개인 강사면 원천징수 후 송금 (매월 10일 신고).
→ 통상: 1차 (강의 시작) 30% / 2차 (강의 중간) 30% / 3차 (강의 종료) 40% 분할 또는 종료 후 일시지급.

### Q5. 학생이 현금영수증 요청 시?

→ B0023 시스템 이미 구축. `/admin/applicants` 에서 신청자 row 의 [현금영수증] 버튼 클릭 → 발급 정보 입력 → 홈택스 수동 발행 (자동 X). 영수증 발급 카운트 표시.

### Q6. 회계사 위임 가능?

→ 일반 과세 사업자 = 분기 부가세 + 매월 원천세 + 종소세 → 회계사 위임 권장. 월 30~50만원 수준.
→ 1기 단일 cohort + 단일 운영자 (노아) 라면 셀프 가능. 다음 기수 + 매출 증가 시 회계사 검토.

## 12. 1기 실전 — Cowork + 강사에게 세금계산서 받기 (초보자 step-by-step)

> 2026-06-26 작성. 노아 = 1인 운영자 + 회계사 위임 X 가정.

### 12.1 핵심 개념 정정 — 방향 헷갈리지 말기

**세금계산서 발행 방향** (절대 헷갈리면 안 됨):

```
공급자 (돈 받는 쪽)          공급받는자 (돈 주는 쪽)
   = 매출자                     = 매입자
   = Cowork / 강사     →        = Dropdown / 노아
   = 발행함                      = 받음
```

**공급자가 본인 홈택스 로그인 → 발행** → 공급받는자에게 자동 전달 (이메일 알림 + 홈택스 매입 탭에서 확인).

### 12.2 누가 누구에게 정보를 먼저 보내나

| 정보 | 누가 보내나 | 왜 |
|---|---|---|
| **사업자등록증 사본 (PDF)** | 공급자 → 공급받는자 | 사기 방지. 공급자가 진짜 사업자인지 확인 |
| **통장 사본 (PDF)** | 공급자 → 공급받는자 | 송금 계좌 확인. 예금주명 = 사업자 상호와 일치 검증 |
| **사업자번호 + 회사명 + 담당자 이메일** | 공급받는자 → 공급자 | 발행 시 "공급받는자" 정보 필수 입력 |

**Dropdown (노아) 입장**:
- Cowork / 강사 가 **사업자등록증 + 통장 사본** 을 먼저 보냄 (이미 강사 1인은 보냄)
- 노아는 **사업자번호 (154-28-02110) + 회사명 (Dropdown) + 담당자 이메일 (hello@dropdown.xyz)** 만 알려주면 됨
- 노아 본인의 사업자등록증 사본은 굳이 안 보내도 됨 (사업자번호로 자동 조회 가능)

### 12.3 "돈 나중에 줘도 되나?" — 공식 답변

**YES. 합법.** 부가세법 명시:

- **부가가치세법 §16** (용역 공급시기): "역무의 제공이 완료된 때" 또는 "대가의 각 부분을 받기로 한 때 (약정에 의함)"
- **부가가치세법 §32** (세금계산서 발급): "공급시기에 발급"
- **시행령 §62**: 공급시기 ± 1개월 안 발행 OK (가산세 없음)
- **시행령 §66 ① 7호**: 월합계 세금계산서 = 매월 말 1장으로 발행 가능 (강사료 등 정기 거래)

**일반 관행**:
- 세금계산서 발행 → Net 30 / Net 60 / 약정 시점 송금
- 마케팅 / 컨설팅 / 강사료: "용역 완료 후 N일" 약정 표준
- 프로그램형 (1기 7/19 종료): 종료 직후 또는 그 달 말 송금

**약정 명시 권장**: 카톡 / 이메일에 "강의 종료 후 N일 안 송금 예정" 정도 텍스트로 합의해두기. 분쟁 시 근거.

### 12.5 Cowork 12% 산정 — 1기 정확한 금액

- 결제 완료 인원: 10명 (6/22 11명 → 6/23 1명 환불)
- 수강료: 880,000원 (VAT 포함)
- 12% = 880,000 × 0.12 = **105,600원 / 인**
- **총 10명 × 105,600 = 1,056,000원**

**약정 확인 필요** (Cowork 에게 명시적으로 물어볼 것):
1. **산정 기준이 VAT 포함 (880,000) 인가 별도 (800,000) 인가?**
   - VAT 포함: 10 × 880,000 × 0.12 = **1,056,000원**
   - VAT 별도: 10 × 800,000 × 0.12 = 960,000원
2. **환불자 (1명) 차감?** — 일반 관행은 환불자도 청구 (마케팅 활동은 이미 함). 협상 가능.
3. **VAT 포함 가격 / 별도 가격** — Cowork 세금계산서에 공급가액 + VAT 분리 표기됨. 어느 기준으로 12% 인지 명시.

### 12.6 강사 세금계산서 발행 — 강사 1명 케이스

강사가 본인이 "세금계산서 발행해드릴게요" 라고 함 = **강사 = 사업자 (개인사업자 또는 법인) 보유**.

흐름:
1. 강사가 본인 사업자등록증 + 통장사본 보냄 (이미 받음)
2. 노아가 위 12.4 template 으로 Dropdown 정보 회신
3. 강사가 본인 홈택스에서 발행 (공급일자 = 강의 회차 종료일 또는 약정 월말)
4. 노아 hello@dropdown.xyz 로 발행 알림 자동
5. 노아가 약정 시점에 통장사본 받은 계좌로 송금

**다른 강사 2인 분기 확인 필요**:
- 사업자 보유 → 세금계산서 (위와 동일 흐름)
- 사업자 X → 3.3% 원천징수 (송금 시 차감 + 매월 10일 홈택스 신고)

### 12.7 홈택스에서 받은 세금계산서 확인 방법 (Dropdown 입장)

1. **https://hometax.go.kr** 접속
2. 우상단 "로그인" → "사업자" 선택 → 공동인증서 또는 간편인증 (카카오 / 토스 등)
3. 메뉴: **조회/발급 → 전자세금계산서 → 매입** (또는 "건별 조회")
4. 발행일자 범위 지정 → 조회
5. 발행된 세금계산서 list 노출. 공급자명 / 공급가액 / 세액 / 합계 확인
6. 필요 시 PDF 다운로드 → 회계 자료 보관

### 12.8 송금 진행 — Dropdown 입장

1. 세금계산서 받음 + 약정 시점 도래
2. 토스뱅크 또는 다른 거래 은행에서 송금
3. 송금 받는 계좌 = **통장사본에 적힌 계좌** (사기 방지 — 임의 계좌 송금 금지)
4. 송금 후 카톡 / 이메일로 "송금 완료" 통지 + 송금 영수증 (선택)
5. `cohort_expenses` 의 해당 row status = `planned` → `paid`, paid_at 기록 (운영자 manual)

### 12.9 자주 헷갈리는 케이스

#### Q1. Cowork 가 "세금계산서 먼저 주세요" 라고 하면?

→ "발행에 필요한 정보 (Dropdown 사업자번호) 먼저 알려주세요" 의미. 또는 단순 어순 혼동. 본 12.4 template 회신.

#### Q2. 강사가 사업자 보유 + 본인이 직접 발행 못함 (담당자 부재 등)?

→ 강사 회사 담당자에게 위임. 또는 회계사 위임. 노아 입장에선 받기만 함.

#### Q3. 송금 → 그 다음 세금계산서 발행 (역방향) 도 가능?

→ 가능. 단 발행이 공급시기 ± 1개월 안이어야 안전 (가산세 회피).

#### Q4. 강사료 매번 발행 vs 월합계?

→ 월합계 세금계산서 (시행령 §66 ① 7호) — 매월 말 1장 발행 가능. 다음 달 10일까지 발급. 강사료 정기 거래에 유용.

#### Q5. Cowork 가 VAT 발행 X 면? (간이과세자)

→ 간이과세자 = 세금계산서 발행 불가. 영수증만 발급. 노아는 부가세 매입 차감 X. 송금만 진행.
→ Cowork 가 일반과세자 (사업자등록증에 "일반과세자" 표시) 면 세금계산서 발행 의무.

#### Q6. 외국 회사 / 외국인 강사 (사업자 X) 에게 송금?

→ 별도 분기. 거주자 (한국 183일+) = 3.3% 원천징수. 비거주자 = 조세조약 (보통 22%). 본 1기는 한국 거주 가정.
