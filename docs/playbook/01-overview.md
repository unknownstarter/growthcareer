## 핵심 정책 / 절대 룰

1. **신청-입금 분리** — 신청 폼 ≠ 결제 폼. 입금 안내는 운영자 수동 발송 (B0007 반자동 모델). 자동 결제 시스템 X.
2. **운영 페이지 격리** — `/admin/*` (Basic Auth, 다크) 와 `/fan-to-pro/(lms)/*` (Supabase Auth, 라이트 토스 톤) 완전 분리. 두 시스템 통합 금지.
3. **회원가입 페이지 없음** — 학생/강사 onboarding = 운영자 invite + 첫 로그인 강제 PW 변경.
4. **카피 부호 룰** — em dash / interpunct (·) / 곡선 따옴표 / 단일 ellipsis (…) 모두 금지 (CLAUDE.md §6.5).
5. **돈 조항 사용자 동의 의무** — 사례비 / 보장금 등 신규 비용 항목 추가 시 사용자 컨펌 필수.
6. **외부 통합 SDK 오버스펙 금지** — 카톡 / 외부 서비스는 URL / 딥링크로 끝나는지 먼저 확인.
7. **Sage 검토 전 production 배포 금지** — 새 권한 / 인증 / PII 표면이면 의무.
8. **prod Supabase SQL Editor 직접 DDL 금지** — 모든 schema 변경은 `supabase/migrations/` 파일 only.
