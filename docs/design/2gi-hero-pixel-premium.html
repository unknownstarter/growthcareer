픽셀이 사는 곳 (절제)

핵심은 "덜 쓰기". 픽셀이 전면에 나서지 않고 시그니처로만 반짝여서, 클린한 프리미엄 위에 K-엔터 특유의 디지털 무드를 얹어요.

  • 모노 eyebrow + 픽셀 캐럿 - "Cohort_02" 언더스코어 + 깜빡이는 픽셀 커서 (터미널 무드, 스팸 없이)
  • 타이틀엔 마침표 없음 - 짧은 문구 끝 마침표 금지(§6.5). 픽셀은 eyebrow / 프레임 / 칩에만
  • 사진 프레임 = 픽셀 코너 마커 + 미세 픽셀 그리드 - 스캔라인 대신 은은한 도트 그리드
  • 칩 / CTA = 작은 픽셀 스퀘어 불릿 - 라운드 도트 대신 각진 픽셀 하나
  • 나머지 전부 클린 - 헤드라인 / 본문 / 여백은 프리미엄 산세리프. 픽셀은 악센트일 뿐
  • 모노는 Space Mono - 블록 비트맵 폰트 대신 정제된 모노 = 테크 프리미엄 톤
