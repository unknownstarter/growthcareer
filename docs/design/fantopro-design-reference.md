## 0. 한 줄 요약

**"차분한 다크 + 큰 여백 + 정직한 타이포 + 숫자로 신뢰"**. 화려한 효과가 아니라 **절제와 리듬**으로 프리미엄을 만든다. 커리큘럼 같은 정보 밀도 높은 콘텐츠도 위계와 간격으로 읽기 좋게 편다. AI-slop(글로우/그라데이션/중앙정렬 2CTA 템플릿)과 정반대 방향.

핵심 4원칙:
1. **다크 베이스, 라이트 릴리프** - 거의 전체가 near-black. 딱 한두 섹션(FAQ)만 밝게 눌러 리듬을 준다.
2. **큰데 안 시끄러운 타이포** - 디스플레이가 56px 인데 weight 는 500(미디엄). 크게 말하되 소리치지 않는다.
3. **숫자 먼저** - eyebrow 부터 "0원, 60만원, 45명, 16주, 88%, 4.7, 80%" 로 신뢰를 수치화.
4. **섹션 = 반복되는 해부 구조** - 모든 섹션이 [eyebrow → 큰 헤드라인 → 서포트 콘텐츠] 로 같은 뼈대. 예측 가능해서 편하다.

## 1. 컬러 시스템 (실측)

측정된 실제 사용 컬러(빈도순). RGB 옆에 hex 병기.

### 배경 (surface)
| 역할 | 값 | hex | 비고 |
|---|---|---|---|
| 메인 다크 베이스 | rgb(20,25,30) | `#14191E` | 페이지 바탕 |
| 다크 카드/네이비 | rgb(30,37,44) | `#1E252C` | 카드 표면(가장 많이 쓰임, 31회) |
| 딥 블랙 | rgb(23,23,25) | `#171719` | 대비 강한 블록 |
| 라이트 릴리프 | rgb(248,248,248) | `#F8F8F8` | FAQ 등 밝은 섹션 |
| 페일 블루 블록 | rgb(196,229,247) | `#C4E5F7` | 강조 블록(솔리드) |
| 글래스 | rgba(255,255,255,0.15) | - | 카드 위 반투명(딤, 그라데이션 아님) |
| 글래스 다크 | rgba(55,56,60,0.61) | - | 스티키 바 배경 |

### 텍스트
| 역할 | 값 | hex |
|---|---|---|
| 기본(다크 위) | rgb(255,255,255) | `#FFFFFF` |
| 기본(라이트 위) | rgb(51,51,51) | `#333333` |
| 뮤트/보조 | rgb(147,147,147) | `#939393` |
| 뮤트2 | rgb(85,85,85) | `#555555` |
| 액센트(sky) | rgb(137,200,234) | `#89C8EA` |

### 액션 / 액센트
| 역할 | 값 | hex | 비고 |
|---|---|---|---|
| CTA 버튼 | rgb(0,102,255) | `#0066FF` | 원티드 시그니처 블루. **행동색** |
| 데코 액센트 | rgb(137,200,234) | `#89C8EA` | eyebrow/하이라이트. **강조색** |
| 페일 강조 블록 | rgb(196,229,247) | `#C4E5F7` | 솔리드 블록 |

**핵심 인사이트**: 행동색(#0066FF 채도 높은 블루)과 강조색(#89C8EA 부드러운 하늘색)을 **분리**했다. CTA 만 쨍한 블루, 나머지 강조는 차분한 하늘색. 이래서 CTA 가 안 묻힌다.

### 우리 적용 (팬투프로)
- 팬투프로는 이미 **검정 + 핑크(#ec4899) + 남보라(#6366f1)** 다크 톤 보유. 원티드의 "다크 베이스 + 행동색/강조색 분리" 원칙을 그대로 차용:
  - **행동색 = 핑크(#ec4899) 솔리드** (CTA 전용, 쨍하게)
  - **강조색 = 남보라 또는 핑크의 차분한 변주** (eyebrow/하이라이트)
  - 베이스 = near-black(#14191E 계열), 카드 = 한 톤 밝은 네이비/차콜
  - 라이트 릴리프 섹션 1개 정도로 리듬 (우리 LMS 라이트 토큰 재활용 가능)
- ⛔ 하우스 룰: **컬러값 그라데이션 금지, 글로우 금지**(§6.8). 원티드도 그라데이션은 거의 안 쓰고 솔리드 블록 + 딤(alpha)만 쓴다 = 우리 룰과 일치. 그대로 따르면 됨.

## 2. 타이포그래피 (실측)

### 폰트
- 브랜드/디스플레이: **`Wanted Sans Variable`** (원티드 자체 폰트, SIL OFL 오픈소스라 우리도 사용 가능) → 폴백 Pretendard, Apple SD Gothic Neo
- 본문 일부: **`Pretendard Variable`**
- **우리 적용**: 팬투프로는 Pretendard 표준 유지 권장(이미 로드됨). 디스플레이만 개성 주고 싶으면 Wanted Sans 를 디스플레이 전용으로 얹는 것도 OK(라이선스 무료). 단 폰트 2개 이상이면 역할 분리 명확히.

### 타입 스케일 (size / weight / line-height / letter-spacing 실측)
| 역할 | size | weight | line-height | letter-spacing |
|---|---|---|---|---|
| Display (hero) | 56px | 500 | 84px (1.5) | -0.84px (-0.015em) |
| H1 (섹션 대제목) | 36px | 600 | 54px (1.5) | -0.36px (-0.01em) |
| H2 (섹션 제목) | 24px | 600~700 | 36px (1.5) | -0.24px (-0.01em) |
| Subhead | 20px | 700 | 34px (1.7) | -0.2px |
| Body L | 17px | 400 | 28.9px (1.7) | -0.17px |
| Body | 15~16px | 400 | 25.5px (1.7) | -0.15px |
| Body 강조 | 15~17px | 600 | 동일 | 동일 |
| Label / eyebrow | 13px | 600 | 18px (1.4) | **+0.25px (양수)** |
| Caption | 11px | 500 | 14px | **+0.34px (양수)** |

### 타이포 원칙 (여기가 핵심)
1. **행간이 넉넉하다 (본문 1.7, 제목 1.5)**. 정보가 많아도 숨 쉴 틈. AI-slop 은 행간이 좁아서 답답한데 정반대.
2. **큰 글자에 음수 자간 (-0.01~-0.015em)**. 디스플레이/제목을 살짝 조여 프리미엄 느낌.
3. **작은 라벨엔 양수 자간 (+0.25~0.34px)**. eyebrow/캡션을 벌려 또렷하게. (대문자 라벨 느낌)
4. **디스플레이 weight 가 500(미디엄)**. 900 블랙 아님. 크지만 안 무겁고 세련됨. ← 따라하기 쉬운 포인트.
5. **제목 weight 는 600~700**, 본문 400, 강조 600. weight 3단계로 위계.

### 우리 적용
- 위 스케일 표를 **거의 그대로** 토큰화 가능. Pretendard 는 Wanted Sans 와 metric 이 비슷해서 자간/행간 값 재사용 OK.
- ⛔ 하우스 룰: 짧은 UI 문구(타이틀/서브/라벨/CTA/빈상태/토스트) **끝 마침표 금지**(§6.5). 원티드 헤드라인도 마침표 없음 = 일치.

## 3. 스페이싱 / 라운드 / 엘리베이션 (실측)

### 라운드 (border-radius 빈도순)
| 값 | 용도 |
|---|---|
| **24px** | 카드 기본(가장 많음, 39회). 큼직한 라운드가 브랜드 시그니처 |
| 1000px / 9999px | 알약형 버튼/칩 |
| 8px / 10px / 6px | 작은 요소(태그, 인풋 등) |
| `4px 20px 20px 20px` (비대칭) | **말풍선형 코너** - 후기/인용 카드에 사용 |

**인사이트**: 카드는 24px 큰 라운드로 부드럽게, 버튼은 완전 알약형(pill), 후기 카드는 한 모서리만 각지게(말풍선) = "누가 말하는 느낌". 라운드 값으로 의미를 준다.

### 스페이싱
- 섹션 간 **아주 큰 수직 여백**(데스크탑 full 12,145px / 13개 섹션 = 섹션당 평균 900px+). 여백이 곧 프리미엄.
- 콘텐츠 폭은 중앙 정렬 컨테이너(대략 1000~1120px), 좌우 넉넉한 거터.

### 엘리베이션
- 그림자 거의 안 씀. **표면 컬러 차이(#14191E vs #1E252C) + 얇은 보더(white/0.15)** 로 층을 만든다. ← 다크 테마에서 그림자 대신 표면 대비로 depth. 우리 룰(검정 하드 드롭 OK, 글로우 금지)과 궁합 좋음.

### 우리 적용
- 라운드: 카드 20~24px, 버튼 pill, 후기 카드 말풍선 코너 차용.
- 여백: 섹션 간 여백을 지금 팬투프로보다 더 크게. "덜 넣고 크게 벌리기".

## 4. 페이지 섹션 구성 (앵커별 해부, 위 → 아래)

원티드 랜딩의 13개 섹션 순서와 각 역할. **이 순서 자체가 전환 설계**다.

| # | 섹션 | 역할 | 표현 방식 |
|---|---|---|---|
| 1 | **Hero** | 후킹 + 핵심 오퍼 | 다크 배경 + 3D 렌더 오브젝트 + 디스플레이 타이포 + 숫자 eyebrow + 스티키 CTA 바 |
| 2 | **문제 제기** | 공감("아직 취업 전이신가요?") | 4개 후기형 카드(직군+나이 태그 + 고민 인용, 말풍선 코너) |
| 3 | **가치 전환** | "교육 과정이 아닌 커리어 캠프" | 실제 공간 사진 카드 + 텍스트 + 파트너 로고 행 |
| 4 | **차별점** | "무엇을 배웠는지보다 무엇을 만들었는지" | 하늘색 하이라이트 리스트(체크 4행) |
| 5 | **커리큘럼 개요** | "16주 동안 이렇게 만들어갑니다" | 4~5 아이콘 컬럼(스테이지 요약) |
| 6 | **지원 혜택** | "필요한 모든 것을 지원" | 다크 카드 그리드(혜택별 라벨 + 금액) |
| 7 | **강사/멘토** | 신뢰(사람) | AI 강사 1명 대형 카드 + 멘토 6명 3x2 그리드(정사각 헤드샷) |
| 8 | **16주 로드맵** | 커리큘럼 상세 | **스테이지 레일 + 상세 패널** 타임라인 |
| 9 | **주요 툴** | 도구 신뢰 | Claude + Ennoia 2 카드(로고 + 설명) |
| 10 | **왜 여기인가** | 성과 증명 | 숫자 스탯 3카드(연 300명+ / 완주율 88%·만족도 4.7 / 취업률 80%) |
| 11 | **지원 자격** | 자격 필터 | 2컬럼 다크 박스(지원 자격 / 지원 대상) |
| 12 | **FAQ** | 이의 해소 | **라이트 배경** + 아코디언 |
| 13 | **Footer** | 법적/링크 | 다크 |

### 전환 흐름의 논리
후킹(1) → 공감/문제(2) → 재정의(3) → 차별점(4) → 무엇을 얻나(5,6) → 누가 가르치나(7) → 어떻게 진행되나(8,9) → 증거(10) → 자격 확인(11) → 이의 해소(12). **"의심 → 해소"를 순서대로 밟는다.** 팬투프로 전환 개선(P1~P5)과 같은 골격이라 재사용 쉬움.

### 우리 적용 (팬투프로 원데이/PRO)
- 원데이(관광객)용은 이 흐름을 **짧게 압축**: 후킹 → "여기서만 되는 경험"(차별점) → 무엇을 하나(경험 구성) → 누가(현직 DJ) → 증거(사진/후기) → 예약 CTA. 자격 필터/FAQ 는 가볍게.
- PRO 용은 원티드 흐름을 거의 그대로(사다리/커리큘럼/멘토/성과).

## 5. 커리큘럼 표현 방법 (노아 요청 핵심)

원티드는 커리큘럼을 **두 번, 다른 해상도로** 보여준다. 이게 정보 밀도 관리의 핵심.

### (A) 저해상도 개요 - "스테이지 아이콘 컬럼" (섹션 5)
- 4~5개 아이콘 + 한 줄 라벨(예: "AI 실전 프로젝트", "현직자 멘토링", "AI 포트폴리오", "취업 지원").
- 목적: **한눈에 큰 그림**. 스크롤 빠른 사람도 "아 이런 단계구나" 파악.

### (B) 고해상도 상세 - "16주 완성 로드맵" (섹션 8)
- 구조: **좌측 스테이지 레일(1단계~5단계) + 우측 상세 패널**.
- 각 스테이지에 주차(Weeks 1-2 등) + 내용 + **산출물(Outputs)** 명시.
  - 예) 1단계(1-2주) 직무훈련: 취업 장벽 진단서, 직군별 AI 유즈케이스, AI 도구 체인 초안
  - 2단계(3-8주) AI 교육 / 3단계(9주) 실전 적용 / 4단계(10-15주) 포트폴리오 제작·발표 / 5단계(16주) 취업 지원
- 목적: **진지한 사람에게 신뢰**. "결과물(산출물)"을 단계마다 박아 "배우는 게 아니라 만든다"를 증명.

### 표현 기법 정리
1. **단계(스테이지) 메타포** - 1단계~5단계 넘버링. 실제 순서가 있는 콘텐츠라 넘버링이 정당(§frontend-design: 넘버링은 진짜 순서일 때만).
2. **주차 + 산출물 쌍** - 각 단계 = 기간 + 만드는 것. 시간과 결과를 같이.
3. **개요/상세 2단 노출** - 빠른 독자와 꼼꼼한 독자 모두 커버.
4. **타임라인 = 레일 + 패널** - 좌 네비(단계) 우 콘텐츠. 모바일은 세로 스택.

### 우리 적용
- 원데이(관광객): 커리큘럼을 **"하루의 흐름(타임라인)"** 으로. 예) 도착·환영 → 장비·부스 소개 → 1:1 기초 → 믹싱 실습 → **진짜 무대에서 내 셋 플레이** → 사진/영상. 단계마다 "얻는 것"(경험/결과물) 명시. 원티드의 "주차+산출물"을 "시간대+경험/결과물"로 변주.
- PRO: 원티드의 스테이지 레일+패널 그대로. 우리는 이미 LMS 에 커리큘럼 데이터 있음.

|---|---|
| **히어로 오브젝트** | 3D 렌더(광택 키캡) + 거대 아웃라인 워드("FRONTIERS"). 실사 아닌 렌더로 브랜드 오브제 |
| **공간 사진** | 실제 장소(wanted ground) 사진을 24px 라운드 카드에 담음. "진짜 공간"의 신뢰 |
| **멘토 헤드샷** | **정사각 420x420 원본 → 140px 균일 표시**, 라운드. 통일감(다 같은 크롭/사이즈) |
| **파트너 로고** | 가로 로고(Claude, Ennoia 등)를 한 행에 정렬. 회색조/모노로 차분하게 |
| **아이콘** | 라인 아이콘, 단색. 스테이지 개요에 사용 |

**인사이트**:
- 사람 사진은 **무조건 균일 규격**(같은 정사각, 같은 크롭). 제각각이면 아마추어처럼 보임. ← 강사 사진 촬영/크롭 가이드로 박제할 것.
- 히어로는 실사보다 **브랜드 오브제(3D/그래픽)** 로 개성. 우리 원데이는 "진짜 클럽/부스" 실사가 자산이니, **실사 + 절제된 그래픽 병행** 가능.
- ⛔ 하우스 룰: 원티드 히어로의 **색수차(chromatic aberration)** 효과는 우리 글로우/그라데이션 금지 취지와 애매하게 걸림. **차용하지 말 것.** 우리는 솔리드/딤만.

### 우리 적용 (원데이 = 사진이 승부)
- 관광객 원데이는 **"어디서도 못 할 순간"이 사진으로 증명**돼야 함. 진짜 부스에서 헤드폰 낀 손님, 무대 조명, 결과물 캡처.
- 사진 규격 가이드: 히어로(가로 와이드 1개 강렬한 것), 경험 스텝(정사각/4:5 균일), 후기(인물+현장).

## 7. 시그니처 장치 (기억에 남는 요소)

1. **스티키 플로팅 글래스 CTA 바** - 하단 고정, 24px 라운드, 반투명 다크, "지원 하기" 블루 버튼 + 마감 날짜/D-day. 항상 보여서 전환 유지. (우리도 이미 sticky-cta-bar 컴포넌트 보유)
2. **숫자 eyebrow** - 헤드라인 위에 "0원, 60만원, 45명" 핵심 숫자 3개. (우리는 중간점 · 대신 일반 구분자 사용)
3. **다크-라이트 리듬** - 전체 다크 중 FAQ 만 라이트로 눌러 지루함 방지.
4. **반복 섹션 해부** - 모든 섹션 [eyebrow → 큰 헤드 → 콘텐츠] 동일 뼈대.
5. **말풍선 코너 후기 카드** - 한 모서리만 각지게(4px) = 말하는 느낌.
6. **개요/상세 2단 커리큘럼** - 아이콘 개요 + 로드맵 상세.
7. **행동색/강조색 분리** - CTA 만 쨍한 블루, 강조는 차분한 하늘색.

## 8. 인터랙션 / 모션 (추정 + 우리 룰)

- 스크롤 등장 fade/slide(원티드류 랜딩 표준), 아코디언 펼침, 스티키 바 상시.
- ⛔ 하우스 룰(§6.7): 신규 페이지는 loading skeleton + 등장 fade-in(stagger) + hover/focus transition + 상태변경 피드백 + `motion-safe:` 접근성. 원티드 수준의 절제된 모션이면 충분. 과한 패럴랙스/글로우 금지.
