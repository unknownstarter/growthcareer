# 서브에이전트 리서치 결과를 대화에만 두고 세션이 끊겨 유실

날짜: 2026-09-24
분류: 프로세스 사고 (산출물 유실)

---

## 무슨 일이 있었나

- 2026-09-23 세션에서 노아가 "1인 바이브코딩 SaaS 사례 (위노트 포함) + 비IT 니치 기회" 리서치를 요청
- Echo 를 백그라운드로 디스패치했고 **결과는 정상적으로 돌아왔다** (사례 6건, 위노트 정체 확정, 페인포인트 7건, 니치 후보 8개, 출처 14건)
- 그런데 같은 시점에 진행 중이던 2기 증명 섹션 작업을 먼저 끝내기로 하고 **"증명 섹션 끝내고 따로 제대로 정리해줄게요"** 라고만 답한 채 세션 종료
- 다음 세션 (2026-09-24) 에서 노아가 "그 조사 어디갔어" 라고 물었을 때 메인 컨텍스트에 없어서 **없는 작업처럼 응답**. 노아가 "이걸 까먹냐" 고 지적
- 이전 세션 jsonl 로그의 task-notification 에서 원문을 복구해 파일로 박제하면서 복원 완료 (정본은 이후 Factor 로 이관, ADR 0020)

## 왜 일어났나

1. **리서치 산출물이 대화 텍스트로만 존재했다.** Echo 프롬프트에 "파일 만들지 말고 텍스트로 반환" 이라고 명시한 게 직접 원인. 토큰 절약 의도였지만 세션이 끊기는 순간 산출물이 증발한다
2. **WORKING-SESSION.md 에 반영하지 않았다.** 핸드오프 파일은 9/21 상태에서 멈춰 있었고 9/23 의 SaaS 리서치 요청 자체가 기록되지 않았다
3. **"나중에 정리해줄게" 로 끝나는 미완결 약속을 추적하는 장치가 없다.** 대화에서만 약속하면 다음 세션은 그 약속의 존재를 모른다

## 어떻게 막을까

1. **서브에이전트 리서치는 파일 산출을 기본으로 한다.** 결정에 쓰이는 리서치는 `docs/research/YYYY-MM-DD-<slug>.md` 로 저장하게 프롬프트에 명시. "텍스트로만 반환" 은 즉석 확인용 단문에만 허용
   → CLAUDE.md §1 에 룰 추가
2. **세션 종료 전 미완결 약속을 WORKING-SESSION.md 에 적는다.** "나중에 정리" 로 남긴 항목은 전부 진행 중 섹션에 기록
   → CLAUDE.md §7.5 업데이트 트리거에 추가
3. **다음 세션 30초 체크에 "직전 세션 미완결 약속" 확인을 포함한다.** WORKING-SESSION 의 진행 중 항목을 먼저 읽는 것으로 충족
