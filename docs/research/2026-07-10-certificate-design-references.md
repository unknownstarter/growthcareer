# 수료증 디자인 리서치 — 오피셜 강화 방향

**작성**: Sophia (Tech Architect) / 2026-07-10
**목적**: Fan to Pro 1기 수료증을 "인쇄해서 액자에 걸 만한 오피셜 수준"으로 끌어올리기 위한 레퍼런스 리서치.
**현재 자산**: `tools/certificate-preview.html`, `src/programs/fan-to-pro/application/certificate/certificate-template.ts`
  - Toss 라이트 톤, 세리프 영문 타이틀 (Times New Roman 24pt) + 산세리프 한글, 흰 배경, Toss 블루 #3182f6 accent 3회 (brand dot, serial, seal).
  - 이중 테두리 (외곽 1mm + 내곽 6mm 안쪽).
  - 발급인: Dropdown / 서명 이미지 slot + seal 원.
  - QR + verify URL 하단 고정.

**결론 요약**: 현 디자인은 "미니멀 Fintech 인증서" 톤이라 오피셜 격이 다소 부족. Ivy League 학위증의 정보 위계 + 정부 문서의 인장 무게감 + K-pop 산업 accent 색을 합친 방향 권장. Slice 2 에서 3~4시간 안 재설계 가능.

## 카테고리 A. 온라인 학습 플랫폼 수료증

### A1. Coursera Verified Certificate

- **레이아웃**: 가로형 A4. 좌측 대학/기업 로고 (예: Stanford, Google) + 우측 Coursera 로고 이중 발급자 구조. 중앙 이름 크게, 하단 학장/디렉터 서명 2인.
- **타이포**: 산세리프 (Source Sans Pro 계열) 100%, 세리프 안 씀. 이름 굵고 크게 (약 32pt 상당).
- **색상**: 흰 배경 + 짙은 남색 (#0056D2 Coursera brand) accent. 하단 배경 grey 밴드.
- **인장**: 없음. 대신 Verify URL + 8자 unique code + Coursera 로고 워터마크.
- **재질 인상**: 디지털 native. 인쇄 안 상정. 화면 공유 최적화.
- **차용 요소**: 이중 발급자 표기 (Growth Career + Union Pictures / DEEPI 협력) 는 유용. Union Pictures 참여 확인서와 별도로 수료증에 파트너 표기.

### A2. edX Professional Certificate (MicroMasters)

- **레이아웃**: 가로 A4. 상단 발급 대학 로고 중앙 배치, 큰 세리프 타이틀 "Professional Certificate".
- **타이포**: 세리프 (Playfair Display 계열) 헤딩 + 산세리프 body 혼합. 학위증 인상 강함.
- **색상**: 크림/오프화이트 배경 (#FDFCF7) + 다크 브라운 (#3A2E1F) 텍스트 + 골드 (#B8860B) accent seal.
- **인장**: 대학 공식 원형 seal (지름 약 30mm), 하단 좌우 학장/디렉터 실 서명 이미지 2인.
- **재질 인상**: parchment (양피지) 톤. 인쇄 상정.
- **차용 요소**: 크림 배경 + 세리프 헤딩 조합이 격조 확보. 흰 배경보다 "오피셜" 느낌 강함.

### A3. Google Career Certificates (Coursera 연계)

- **레이아웃**: 가로 A4. 좌측 Google G 컬러 로고 (Blue/Red/Yellow/Green) + 우측 Coursera 조합.
- **타이포**: Google Sans (산세리프) 100%. Fintech / 테크 톤.
- **색상**: 흰 배경 + Google Blue #4285F4 헤딩.
- **인장**: 없음. Verify code 만.
- **차용 요소**: 우리 현재 디자인과 톤 가장 유사. 오피셜 강화하려면 이 방향 아님.

### A4. LinkedIn Learning Certificate

- **레이아웃**: 세로 A4. 상단 LinkedIn 로고 + 하단 강사 이름/직함/실 서명.
- **타이포**: Söhne 산세리프. 이름 magenta accent.
- **색상**: 흰 배경 + LinkedIn Blue #0A66C2.
- **인장**: 없음.
- **차용 요소**: 강사 서명 개별 표기 (Fan to Pro 강사 4~5명 이름 하단 나열) 검토 가치 있음.

### A5. MasterClass Completion

- **레이아웃**: 가로. 매우 미니멀. 강사 이름 + 강좌 이름 + 수강자 이름 3줄만.
- **타이포**: MasterClass 자체 세리프 (약 40pt 헤딩).
- **색상**: 완전 흑백. accent 없음.
- **인장**: 없음.
- **차용 요소**: 극단적 미니멀은 우리 방향 아님 (오피셜 강화가 목표).

## Growth Career 적용 안 3개

### 안 1. "Ivy Serif + K-pop Blue" (권장)

- **컨셉**: Harvard/Oxford 학위증 톤 + Toss 블루 유지 (K-pop 산업 accent).
- **변경 요소**:
  1. 배경 흰색 → 크림 아이보리 (#FDFCF7)
  2. 영문 헤딩 Times New Roman → Playfair Display 또는 Cormorant Garamond (더 격조)
  3. 한글 헤딩 산세리프 → 한양명조 또는 Noto Serif KR
  4. 인장 지름 26mm → 38mm 확대
  5. 인장 색 Toss 블루 유지 + 원 내부 텍스트 "GROWTH CAREER SEAL / 성실 이수 / 2026" 3단
  6. 이중 테두리 유지 (현재 유지) + 외곽 코너 4개에 미니 K-pop 심볼 (음표 또는 조명) 추가 검토
  7. 서명 슬롯 2인 (Noah 대표 + Union Pictures 대표 파트너 서명 옵션)
- **차별점**: 국내 부트캠프 최초 학위증급 톤 + K-pop 산업 정체성. 인프런/클래스101 대비 확실히 격조 상위.
- **기존 자산 활용**: 90% 유지. 배경색 + 폰트 교체 + 인장 확대만.
- **노아 결정 필요**: (a) 크림 배경 vs 흰 배경 유지. (b) 세리프 한글 (명조) vs 산세리프 유지.

### 안 2. "Korean Official + Red Seal"

- **컨셉**: 서울대 학위증서 / KCCI 인증서 톤. 붉은 도장 + 한글 명조.
- **변경 요소**:
  1. 헤딩 순서 뒤집기 — 한글 "수료증" 크게 (24pt) + 영문 "Certificate of Completion" 작게 (14pt)
  2. 한글 명조 (한양명조 또는 KoPub 돋움 → KoPub 명조)
  3. Toss 블루 → 짙은 네이비 (#0A2540) 로 교체
  4. 인장 색 → 붉은색 (#C41E3A) + 전각 폰트로 "GROWTH CAREER" 원형 배치
  5. 서명 좌측 세로 정렬, 인장 우측 크게 (지름 42mm)
- **차별점**: 국내 정부 문서급 오피셜 톤. 한국 취업 시장에서 신뢰도 높음.
- **기존 자산 활용**: 70% 유지. 색상 시스템 재작업 필요.
- **노아 결정 필요**: (a) K-pop 산업 이미지에 정부 문서 톤이 맞는가. (b) Toss 블루 브랜드 identity 유지 여부.

### 안 3. "Minimal Gold Foil" (프리미엄)

- **컨셉**: MasterClass + Awwwards 톤. 흑백 + 골드 accent.
- **변경 요소**:
  1. 흰 배경 유지 + 검정 텍스트
  2. Toss 블루 accent → 골드 (#C9A961) 로 교체 (인장 + serial + brand dot)
  3. 인장 골드 원 + "GROWTH CAREER" 각인 스타일 (embossed 느낌 CSS box-shadow)
  4. 폰트 유지 (Pretendard + Times)
  5. 이중 테두리 골드 얇게
- **차별점**: 세련된 프리미엄 톤. K-pop 아이돌 프리미엄 굿즈 톤과 어울림.
- **기존 자산 활용**: 95% 유지. 색상 교체만.
- **노아 결정 필요**: (a) 골드가 오피셜 vs 럭셔리 어느 쪽으로 읽히는가. (b) 인쇄 시 골드가 갈색으로 보이는 리스크.

## 원칙 (오피셜 강화 체크리스트)

인쇄 상정 시 다음 요소가 있으면 오피셜 인상 +1:

- [ ] 크림/아이보리 배경 (#FDFCF7 또는 #F9F5EC) — 흰 배경보다 무게감
- [ ] 세리프 헤딩 (한글은 명조, 영문은 Playfair/Garamond) — 산세리프 100% 는 fintech 인상
- [ ] 인장 지름 35mm+ (현재 26mm 확대)
- [ ] 강한 accent 색 1가지 (붉은색 or 짙은 남색 or 골드) — Toss 블루는 fintech 인상
- [ ] 서명 2인 이상 (Noah + 파트너/강사 대표)
- [ ] 발급기관 정식 명칭 + 사업자번호 + 대표자명 3종
- [ ] 이중 테두리 유지 (현재 유지 중)
- [ ] 커리큘럼 요약 5줄 (실무 증빙 강화)
- [ ] Verify URL + QR (이미 있음)
- [ ] 격식체 카피 ("성실히 이수하였음을 증명합니다" 유지 or "본 증서를 수여함" 격상)
- [ ] Cohort 정보 + 발급 일련번호 (이미 있음)

**빠져있는 것** (현재 디자인 대비):
- 서명 2인 (현재 1인)
- 큰 인장 (현재 26mm → 35mm+ 필요)
- 세리프 한글 헤딩 옵션
- 커리큘럼 요약 (실무 5줄)

## 노아 결정 필요 (5건)

1. **방향 선택**: 안 1 (Ivy Serif + Toss 블루) / 안 2 (Korean Official + Red) / 안 3 (Minimal Gold) 중 어느 쪽. 권장은 안 1.

2. **배경색**: 흰색 (#FFFFFF) 유지 vs 크림 아이보리 (#FDFCF7). 크림이 오피셜 +1 이지만 브랜드 라이트톤과 미묘한 차이.

3. **한글 헤딩 폰트**: 산세리프 (Pretendard) 유지 vs 세리프 (Noto Serif KR / 한양명조) 교체. 세리프가 오피셜 +1 이지만 브랜드 톤 어색해질 수 있음.

4. **서명 2인 여부**: Noah 단독 vs Noah + Union Pictures 파트너 대표 (또는 강사 대표 이재원 등). 2인이 오피셜 +1 이지만 상대측 컨펌 필요.

5. **커리큘럼 요약 삽입**: 현재 program name + duration + cohort 3종. 여기에 "실무 이수 항목 5줄" 추가 검토. 예: "라이브 사운드 설계", "무대 조명 오퍼레이션", "카메라 리깅", "안전 프로토콜", "현장 실습 (Union Pictures 공연)". 실무 증빙 격상되지만 페이지 여백 재배치 필요.
