## 0. 원 요청

노아 원문 요약:

1. 팬투프로 웹에서 만든 **디자인 시스템과 정의들을 템플릿화**해서 다른 프로덕트를 만들고 싶다
2. **1인 바이브코딩으로 SaaS 를 만들어 매출을 내고 매각까지** 한 사례를 찾아 분석해달라 (유튜브에서 본 "위노트" 가 그 중 하나)
3. AGI 시대에 다들 우왕좌왕할 때 기회가 많을 텐데 발견을 못 하고 있다. **아주 사소하지만 팔 수 있는 것**을 찾고 싶다
4. 타깃: 재무, 회계, 영업, 마케팅, 은행, 카페, 개인사업자, 미용사처럼 **IT 지식이 적어 수작업이 많은 사람들**. 중소기업 사장, 개인사업자 대표, 부업 직장인 포함
5. 삼쩜삼이나 회계 서비스에서 발생하는 문제는 없는지도 확인

> 주의: 이 리서치는 2026-09-23 세션에서 완료됐으나 정리본을 전달하기 전에 세션이 끊겼다. 대화에만 있던 산출물은 유실된다는 게 교훈. 리서치 결과는 항상 `docs/research/` 에 파일로 남긴다.

**공통 성공 요인**
1. 좁고 지루한 니치
2. build in public 유통 = 광고비 0
3. 단순한 제품을 반복 개선
4. 유료 100~500명 x 월 5만~10만원이면 생계 성립

**생존자 편향 경고**
위 스타들은 대부분 **매각하지 않고 운영**한다. 실제 "1인이 만들어서 exit" 은 Headlime, HitTail 처럼 예외적이고 배수도 3배 내외로 소액이다. "만들어서 판다" 보다 **현금흐름이 나오는 자산을 소유하고 운영**하는 쪽이 훨씬 흔한 실현형이다. ShipFast 의 하락은 AI 시대 모방과 포화 리스크의 실증 사례다.

## 2. 위노트 정체 확인

- **위노트 (weenote.kr)** = **학교와 심리상담 관리 데스크톱 프로그램**. 개발자는 **민상기 (필명 클래스비누)**, 인디펍 공동창업자와 동일 인물 [HIGH]
- 핵심 차별점은 **로컬 저장** (클라우드 아님). 민감한 상담 정보 유출을 걱정하는 상담센터가 로컬 방식을 선호한다. 국내에 클라우드 상담툴은 많지만 **로컬형이 빈틈**이었다는 게 본인 설명. 학교 상담교사 연수에 약 300명이 신청할 만큼 니치 침투 [MED, 본인 SNS 발언]
- **매각 기록은 검색상 확인되지 않는다.** 유튜브에서 회자되는 위노트 매각이나 월매출 숫자는 1차 확인이 불가능해 소문 또는 추정으로 취급해야 한다. 노아가 본 영상 링크를 주면 그 숫자만 따로 검증 가능
- 진짜 교훈은 매각액이 아니라 **비IT 출신이 자기가 몸담은 도메인의 로컬 니치를 1인이 독점**한 구조다. 노아의 관심사와 정확히 일치한다

## 3. 한국 소상공인, 개인사업자, 부업러 페인포인트와 기존 서비스의 빈틈

1. **종소세와 부가세 신고 불신 (삼쩜삼 갈등)** - 환급액의 10~20% 수수료 반발, 과장된 환급액 제시, 이미 직접 신고한 건에도 수수료 청구, 보험 중복청구 미검증, 세무사 업계 반발. **빈틈: 정직한 견적 + 국세청 원클릭 대비 비교를 투명하게 보여주는 신뢰 레이어** [HIGH]
2. **매출과 정산이 안 맞음** - 카드사 마감과 입금 주기 때문에 영업일 기준 정산이 안 된다. 캐시노트가 이 지점을 긁어 유니콘이 됐다. **빈틈: 캐시노트가 안 잡는 초세분 업종 (1인 미용, 공방, 과외, 반찬가게)** [HIGH]
3. **급여명세서, 4대보험, 수당 수기 계산** - 매달 연장/야간/휴일수당, 소득세, 4대보험을 손으로 계산. 캐시노트가 기능을 냈지만 소외 업종이 많다 [MED]
4. **비IT 사장의 엑셀 + 카톡 + 종이 잔존 업무** - 견적서, 거래명세서, 예약, 재고, 단골 관리가 전부 수기. 글로벌에서도 "Excel + WhatsApp" 이 boring SaaS 금맥으로 지목된다 [MED]
5. **세무사와 사장 사이 자료 수집** - 증빙 요청이 카톡에 파편화 [MED, 추정]
6. **부업 직장인의 사업소득 신고 공포** - 크몽, 스마트스토어, 유튜브 수익 신고를 몰라서 방치. 삼쩜삼의 주 타깃이지만 불신이 크다 [MED]
7. **예약 노쇼와 문자 응대** - 미용, 네일, 필라테스, 병의원. 네이버 예약이 일부 잡지만 커스텀 리마인드와 재방문 자동화는 빈틈 [MED, 추정]

## 4. 1인이 노릴 만한 니치 후보 8개

각 항목: 대상 / 아픔 / 최소 제품 / 지불 의향 / 유통 / 리스크

1. **로컬 저장형 상담 기록툴 (위노트 인접)**
   심리상담, 언어치료, 방문요양 소규모 센터 / 민감정보 클라우드 불안 + 엑셀 관리 / 로컬 저장 데스크톱 또는 브라우저 로컬 기록 앱 / 월 2만~5만원 또는 라이선스 / 협회, 연수, 카페 / 니치 크기가 작고 세일즈 발품이 필요

2. **미용실과 네일 단골 리텐션 + 노쇼 방지**
   재방문율과 노쇼가 매출에 직결되는데 카톡 수기 / 예약 리마인드 문자 + 시술 이력 + 재방문 쿠폰 자동화 / 월 3만~5만원 / 미용재료상, 인스타, 지역 커뮤니티 / 네이버예약, 카카오와 기능 중첩

3. **부업러 세금 겁 제거 툴 (반삼쩜삼 포지션)**
   스마트스토어, 크몽, 유튜브 부업 직장인 / 신고 방법을 모름 + 삼쩜삼 불신 / 플랫폼 수익 CSV 를 넣으면 예상 세액 + 홈택스 원클릭 대비 "이게 진짜 필요한지" 정직 판정 / 건당 5천~2만원 또는 구독 / 부업 유튜브와 블로그 제휴 / **세무대리 규제선** (직접 신고 대행은 세무사 영역)

4. **1인 공방과 수제 판매자 견적서, 거래명세서 생성기**
   견적과 명세서를 매번 한글이나 엑셀로 작성 / 폼 입력 후 브랜드 PDF 즉시 생성 + 카톡 전송 링크 / 월 1만~2만원 / 아이디어스, 인스타 셀러 커뮤니티 / 무료 대체재가 많아 지불 의향이 낮을 수 있음

5. **동네 학원과 과외 수납, 출결, 리포트**
   수납 독촉과 출결, 학부모 리포트가 수기 / 출결 체크 후 자동 수납 알림 + 월 리포트 카톡 / 월 3만~7만원 (원장은 지불력이 있음) / 원장 카페, 지역 / 클래스팅, 아이엠티처 등 경쟁

6. **세무사와 사장을 잇는 자료 수집 파이프**
   소규모 기장 세무사 사무실 / 증빙이 카톡에 파편화 / 사장에게 링크를 보내면 영수증을 촬영 업로드, 세무사 대시보드에 집계 / 사무실당 월 5만~10만원 (B2B 라 높음) / 세무사 직접 영업과 커뮤니티 / 세일즈 사이클이 길고 자비스, 경리나라와 경쟁

7. **고퀄 랜딩 + 예약 원페이지 for 로컬 사장** (노아 강점 직결)
   필라테스, 공방, 카페, 병의원 / 인스타만 있고 예약과 소개 페이지가 없음 / 업종별 프리셋 템플릿 + 예약 폼 / 제작 30만~50만원 + 월 유지 2만원 / 인스타 before after, 지역 / 크몽, 아임웹과 경쟁하므로 **디자인 퀄리티가 유일한 해자**

8. **인수창업 (HitTail 모델)**
   노아 본인 / 0에서 1로 가는 유통이 제일 어려움 / Acquire.com 이나 Flippa 에서 매출이 나오는 방치된 마이크로 SaaS (7천만원~2억원대) 를 사서 **디자인, 온보딩, 전환율만 고쳐** 되팔기 / 인수한 기존 고객이 곧 유통 / 초기 자본과 실사 리스크. **노아의 고치는 손이 가장 잘 먹히는 각도**

## 5. 우리가 이미 가진 템플릿 자산 (레포 실측)

노아의 "템플릿화" 질문에 대한 답. 새 프로덕트를 시작할 때 0에서 시작하지 않아도 되는 부분이다.

### 바로 재사용 가능

| 자산 | 위치 | 재사용 가치 |
|---|---|---|
| 공통 UI 컴포넌트 7종 | `src/shared/ui/` (button, card, modal, status-badge, section-header, sticky-cta-bar, cn) | 라이트 디자인 시스템 기반. SaaS 대시보드에 바로 적용 |
| 네비게이션 세트 8종 | `src/shared/navigation/` (header, footer, wordmark, nav-link, sub-nav, mobile-nav, locale-switch, cta) | 브랜드만 갈아끼우면 됨 |
| 디자인 토큰 + 컴포지션 룰 | `docs/design-system-composition.md`, `docs/design/fantopro-design-reference.md` | 토큰 시트 매핑 방식이 이미 문서화 |
| Supabase 서버 클라이언트 + RLS 패턴 | `src/shared/supabase/`, `supabase/migrations/` 52개 | 인증, 권한, 마이그레이션 관례가 이미 검증됨 |
| 에러 코드 taxonomy | `src/shared/errors/codes.ts` | 관측성 Tier 1 그대로 이식 |
| 분석 이벤트 트래킹 | `src/lib/analytics`, `tools/analytics-summary.mjs`, `tools/ga4-report.mjs` | GA4 + 자체 DB 양쪽 적재 퍼널. SaaS 전환 측정에 그대로 필요 |
| 2단계 신청 폼 패턴 | `application/submit-application.ts` + 멱등성 처리 | 온보딩, 결제 전 리드 수집에 재사용 |
| 메시지 템플릿 시스템 | `messages/templates.ts` + 테스트 | 알림 문구를 코드로 관리하는 틀 |
| 운영자 대시보드 패턴 | `admin-actions.ts`, `finance-actions.ts`, 폴링 자동 반영 | 어떤 SaaS 든 백오피스가 필요하다 |
| 자동화 스크립트 83개 | `tools/*.mjs` | 캡처, PDF, E2E, 부호 검사 파이프라인 |
| 워크플로우 규율 | `CLAUDE.md`, `docs/lessons/` | 사고 재발 방지 시스템 자체가 자산 |

### 템플릿화하려면 추가로 필요한 것

- **결제** - 현재는 계좌 입금 수기 확인. SaaS 는 구독 결제가 필수 (토스페이먼츠, 페이플, Stripe 중 택1)
- **멀티테넌시** - 지금은 단일 프로그램 전제. 고객사별 데이터 격리 설계 필요
- **셀프서비스 가입** - 지금은 운영자 invite 전용 (LMS 룰). SaaS 는 셀프 가입이 기본
- **사용량 기반 과금 계측** - 없음

## 6. 권고

1. **디자인 퀄리티가 해자인 각도부터 검증한다.** 후보 7번 (로컬 사장용 고퀄 랜딩 + 예약) 과 2번 (미용 리텐션) 은 노아의 결과물이 아임웹, 크몽 대비 즉시 차별화된다. AI 시대에 기능은 복제돼도 **미감과 완성도는 아직 느리게 복제**된다
2. **build first 가 아니라 distribution first.** Levels 와 Marc Lou 성공의 90%는 유통이지 코드가 아니다. 반대로 ShipFast 의 하락은 유통 없이는 모방에 먹힌다는 증거다. **커뮤니티나 오프라인 채널이 이미 존재하는 니치** (협회, 재료상, 원장 카페) 부터 고른다
3. **exit 은 목표가 아니라 옵션으로 둔다.** 실제 1인 exit 은 순이익 3배 내외 소액이 흔하다. 만들어 파는 것보다 **월 현금흐름 자산을 1~2개 소유**하는 쪽이 현실적이다. 정 팔고 싶다면 Acquire.com 배수를 역산해 처음부터 순이익과 이전 가능성 (문서화, 자동화) 을 갖춰 설계한다
4. **인수창업 (8번) 을 병행 검토한다.** 0에서 1을 만드는 유통이 가장 어려운데, 노아의 강점은 "고치는 손" 이다. HitTail 모델은 그 강점이 가장 잘 먹히는 지름길이다

## 7. 열린 질문

- 노아가 본 위노트 유튜브 영상의 정확한 링크. 그 숫자만 따로 검증 가능
- 3번, 6번 등 세무 인접 아이디어의 **세무사법과 세무대리 규제선** 확인 필요. 직접 대행은 금지 영역이라 Sage 또는 법률 확인이 선행돼야 함
- 타깃 업종의 실제 지불 의향은 **인터뷰 5명 전에는 전부 추정**이다
