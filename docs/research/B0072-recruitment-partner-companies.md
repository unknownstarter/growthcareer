## Executive Summary

- **거시 트렌드 (HIGH)**: K-pop 4대 기획사 (HYBE / SM / JYP / YG) 모두 외국인 채용 확대 명시. HYBE 는 트레이니 28% 가 외국 국적, 단일 시점 60+ 공고 오픈. SM 은 최근 신규 공고에 "외국인 지원 가능" 명시. 다만 **한국어 (TOPIK 4+ 권장)** 필수 요건.
- **비자 현실 (HIGH)**: E-7-1 (Professionals) 2026 salary floor **연 3,112만원**. 학위/전공-직무 매치 miss 가 rejection 1위 사유. 대부분 마케팅/PR 은 code 2731 (Product Planning Expert) 로 파일.
- **채용 pool 구조**: (a) 대형 기획사 = 정규직 (마케팅/글로벌 PR), (b) 공연 제작사 = 프로젝트 담당자 + 파트타임 스탭, (c) 팬 플랫폼 = 개발/CX/글로벌, (d) 리테일/굿즈 = 영어 화자 우대 CX/오퍼레이션.
- **우리 학생 → 매칭 현실**: 4주 과정 수료 + Union Pictures 실전 참여 이력 → (b) 파트타임 스탭 진입이 가장 realistic. (a) 대형 기획사 정규직은 TOPIK 4+ 필수라 language gating 이 큼. (d) 리테일/굿즈가 non-Korean 화자에게 가장 진입 낮음.
- **파트너십 접촉 우선순위**: 이미 인연 있는 **Union Pictures + Show Note (Kakao Ent 계열)** 부터. 그다음 Live Nation Korea (교육 프로그램 파트너십 이력 있음).

## 우선순위 A (5개) — 노아 즉시 접촉 권장

**선정 근거**: (i) 외국인 채용 이력 있음 + (ii) 접촉 채널 명확 + (iii) 우리 학생 pool 과 role 매칭 가능성.

1. **유니온픽처스** — 기존 인연 (DEEPI 통해). 파트타임 스탭 + 프로젝트 담당자 양방향 매칭 가능. **1기 수료자 → 공연 참여확인서 발급 흐름** 이미 있음. 여기서 시작해야 함.
2. **Show Note (Kakao Ent 계열)** — 해외콘서트 투어 매니저 = 영어 필수. 이메일 `thdekdo@shownote.co.kr` 담당자 오픈. Cold outreach 가장 자연스러움. 매치 role: Junior Tour Coordinator.
3. **Live Nation Korea** — 이미 EnterJobEdu 와 인턴 채용 연계 프로그램 운영 중. 우리는 외국인 특화 + 공연 실무 4주 = 벤치마크 대비 differentiation 명확. LinkedIn 담당자 콜드 아웃리치 + EnterJobEdu 파트너십 문의.
4. **HYBE (Weverse 포함)** — careers.hybecorp.com 60+ 공고. Global Artist PR / Global Strategy 직군은 명시적으로 외국인 오픈. TOPIK 4+ 학생 pool 이 filter 되지만 **top-tier 학생 5~10%** 는 매칭 가능. 담당자 접촉: 공식 페이지 + LinkedIn HYBE Recruiting Team.
5. **Ktown4u** — non-Korean 화자에게 가장 진입 낮은 role (COEX 오프라인 CX + 글로벌 이커머스 CS). 학생 pool 의 median (TOPIK 3 이하 포함) 도 매칭 가능. HR 이메일 + Jobkorea 페이지.

## Open Questions (노아 확인 필요)

1. **파트너십 형식**: 단순 채용공고 forwarding 수준 vs 정식 MoU (인턴 채용 연계) 어디까지 목표? Live Nation×EnterJobEdu 모델 벤치마크?
2. **Union Pictures 로부터 얼마나 push 가능?** — DEEPI 인연 있으니 여기서 시범 매칭 파일럿 (2기 수료자 3~5명) 부터 검증 후 확장 권장. 노아 판단.
3. **TOPIK gating 어떻게 표시할 것인가?** — 학생 pool 의 절반 이상이 TOPIK 3 이하. HYBE/SM/JYP 정규직 role 은 "TOPIK 4+ 필수" 로 사전 필터 → 학생 실망 방지.
4. **비자 지원 어디까지?** — E-7 sponsor 는 파트너사가 해야 함. 우리는 매칭 + 서류 코칭까지가 realistic. 이 경계 명확히.
5. **매칭 = 사람 vs 룰 vs AI?** — BACKLOG B0075 관련. 초기 5개 파트너사 × 1~2 role 규모면 rule-based (수동 태그) 로 충분. AI 는 11월 이후.

## Recommendation

**단기 (2기 launch 전, 8월 안)**: 우선순위 A 5개 중 **Union Pictures 부터** 파일럿 시작. Show Note + Live Nation Korea 는 콜드 아웃리치 이메일 템플릿 (Echo + Aria 협업) 준비. HYBE / Ktown4u 는 학생이 직접 지원하는 채널 소개 + 서류 코칭 wrapper 만.

**중기 (2기 진행 중, 9~10월)**: 우선순위 B 8개 outreach. CJ ENM (KCON 시즌 전) + SM/JYP (autumn 공채 시즌) 타이밍.

**장기 (3기+, 11월~)**: 매칭 시스템 rule-based → AI 전환 (B0075). 파트너사 20+ 개 목표.

**리스크**:
- 파트너사 접촉 전 학생 pool 의 TOPIK 수준·비자 상태 정확히 파악 필수. 낚시 outreach → 파트너사 실망 → 관계 손상 risk.
- E-7 code 미스매치 컨설팅 능력 부족 시 학생 취업률 misleading. HaniSeoul / KOWORK 같은 비자 컨설팅 파트너십도 고려.
