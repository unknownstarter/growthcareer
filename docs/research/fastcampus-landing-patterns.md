## Korean Copy Patterns to Adopt
- **질문형 도입 훅**: "혹시 오늘 하루, 숏츠 몇 개나 보셨나요?" / "장르물이 땡기는 날엔?" — Kenter: "K-pop 무대 뒤가 궁금했던 적 있나요?"
- **부정 → 긍정 반전**: "단순히 AI 영상 툴 강의가 아닙니다. 만들고 끝인 강의도 아니예요." → Kenter "교육이 아닙니다. 커리어 진입로입니다."
- **단정형 + 보장 N가지**: "왼손 아카데미 챌린지는 3가지를 보장합니다. 01 365일 실시간 Q&A … 02 … 03 …"
- **D-N 카운트다운 + ⚠ 이모지 박스**: "⚠ 이 강의 5월 1일 수강료 인상 확정 ⚠"
- **수치 직접 인용**: "29.6만 구독자", "누적 2억 6천만", "21만뷰" — 숫자는 박스 안에 크게.
- **Step N — 부제목 — 본문 3~5줄** 패턴 (3/3 동일)
- **FAQ는 짧은 단정형 답변** — paradox는 1~3줄로만 답.
- **환불 보장 카피**: "수강 시작 후 7일 이내, 5강 미만 100% 환불" → Kenter는 환불 정책을 명문화하면 신뢰 ↑.
- **할부 강조**: "월 N원 / 12개월 무이자 할부 시" — 880,000원 → "월 73,333원" 환산 카피 권고.
- **"평생소장 / 평생수강"** 키워드는 Kenter의 1회성 부트캠프와 맞지 않으므로 → "수료증 + 동문 네트워크 평생 유효" 등으로 변형.

## Pricing Section Anatomy
- 정렬 순서: ① 정가(권장 소비자 가격) → ② 할인 금액 (-N원) → ③ 할인 판매가 → ④ 할인율 % 배지 → ⑤ 월 할부가 (12개월 무이자 시) → ⑥ 적립 P → ⑦ 카운트다운 → ⑧ CTA 버튼 ("수강 신청" / "바로 구매하기")
- **할인 표시**: 큰 % 배지 (49% / 75% / 42% / 69%) + 정가에 취소선 의미 (텍스트 라벨 "권장 소비자 가격" / "정가")
- **카운트다운 위치**: 가격 박스 바로 아래 또는 위, 가격 인상 시점(예: 5월 1일 14:59:00 KST = 2026-04-30T14:59:00.000Z)을 ISO로 명시.
- **묶음/패키지 보너스 가격**: aishorts는 페이지 중반에 패키지(75% 할인) 박스를 한 번 더 박아 "단품 vs 패키지" 가격 비교를 한 컴포넌트에 노출.
- **CTA 카피**: "수강 신청" / "수강 신청 버튼" / "바로 구매하기" / "수강권 선택하기" — 단순·동사형.
- **반복 빈도**: 가격/CTA가 페이지 안에 평균 4~6회 등장. Hero · 가격 인상 박스 · 패키지 박스 · FAQ 직후 · 하단 sticky.
- **할부**: "12개월 무이자 (간편 결제 제외) / 7개 카드사" — 신뢰 푸터 고정.
- **적립금**: "최대 N P 적립" — Kenter는 미적용 시 생략 가능.
