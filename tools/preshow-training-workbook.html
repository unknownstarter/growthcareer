How to use

워크북 사용법

강의 자료가 아니라 실습 도구입니다. 순서대로 따라 하면 현장에서 몸이 반응합니다.

학습 3단계 (챕터마다 반복)

  1. 시나리오 읽기 / 본인이 그 자리에 있다고 상상합니다.
  2. 답 적기 / 정답을 보기 전에 본인 생각을 먼저 적습니다.
  3. 현장 체크 훑기 / 실전 투입 직전에 다시 꺼내 봅니다.

01 / Safety

공연장 안전과 비상 대응

안전은 관객이 다치지 않는 것을 지키는 일입니다. 도착 첫 30분이 가장 중요합니다.

01.1

도착 시 안전 체크

시나리오콜타임 09:00, 08:30 도착. 매니저는 아직 없습니다. 무엇부터 확인할까요?
실습

Q. 도착 즉시 확인할 것 4가지를 적어보세요.

비상구 위치 / 소화기 위치 / AED 위치 / 무전기 채널과 콜사인. 담당 매니저 이름과 연락처도 저장.
현장 체크
  • 비상 대피 경로 2개 이상 확인
  • 담당 구역 소화기 위치 확인
  • 무전기 채널과 콜사인 저장
01.2

관객 사고와 응급 대응

시나리오스탠딩 앞줄에서 관객 한 명이 쓰러집니다. 주변 관객이 밀리고 있습니다.
실습

Q. 첫 5초 안에 할 두 가지 행동은?

(1) 주변 관객을 뒤로 물러나게 해 공간 확보 (2) 무전으로 위치와 상태 보고 + AED 요청. 반응 확인은 그 다음.
현장 체크
  • 담당 구역 가장 가까운 AED 위치 숙지
  • 무전 응급 채널 코드 암기
  • 보고할 때 위치 / 상태 / 인원 순서로
01.3

화재 / 정전 대응

시나리오공연 중 무대 뒤에서 매캐한 냄새. 관객은 눈치 못 챘습니다.
실습

Q. 정전 시 관객에게 절대 하면 안 되는 말은?

"뛰세요", "빨리 나가세요". 뛰는 행동을 부추기면 압사 위험. 유도등 방향 안내와 침착 요청만 합니다.
현장 체크
  • 비상 대피 경로 2개 (주 + 대체) 숙지
  • 소화기 사용법 확인
  • 지정 집결지 위치 확인
02 / Artist

아티스트 응대와 백스테이지

백스테이지는 일터입니다. 팬심은 집에 두고 옵니다.

02.1

대기실 세팅

시나리오본인은 대기실 담당. 아티스트 도착 55분 전, 온도 조절이 안 되는 것을 발견합니다.
실습

Q. 대기실에 기본으로 있어야 하는 것 5가지는?

의상 걸이 / 조명 있는 거울 / 음료 (또는 냉장고) / 화장대 / 콘센트. 문제 발생 시 임의로 방치하지 말고 매니저에게 바로 알립니다.
현장 체크
  • 도착 전 온도 미리 조정
  • 음료 세팅은 도착 30분 전 완료
  • 담당자 외 출입 최소화
02.2

출입 통제

시나리오패스 없이 온 사람이 "저는 아티스트 아버지입니다" 라고 말합니다. 매니저 확인에는 3분 걸립니다.
실습

Q. 정중히 거절하는 한 문장을 적어보세요.

예: "죄송하지만 출입증 없이는 도와드릴 수 없습니다. 매니저 연락 확인 후 다시 안내드리겠습니다." 규정 명시 + 대안 제시 + 존중 어투.
현장 체크
  • 출입자 명단 사전 확인
  • 아티스트 동선은 관객 동선과 겹치지 않게
  • 임시 출입증 발급 절차 확인
02.3

백스테이지 에티켓

시나리오아티스트와 눈이 마주쳤고, 상대가 살짝 미소 짓습니다. 본인의 반응은?
실습

Q. 백스테이지 4가지 금지 행동은?

(1) 사진 / 영상 촬영 (2) 사인 / 셀카 요청 (3) 개인 대화 시도 (4) SNS 언급. 가벼운 목례만 허용.
현장 체크
  • 휴대폰 무음 + 카메라 잠금
  • 아티스트 관련 SNS 언급 금지
  • 마주칠 때 가벼운 인사만
03 / Audience

관객 입퇴장과 현장 운영

입장 게이트는 공연의 첫인상입니다. 30초의 친절이 컴플레인 하나를 막습니다.

03.1

티켓 확인과 입장

시나리오본인 게이트에 100명이 줄 서 있습니다. 스캐너가 갑자기 멈춥니다.
실습

Q. 스캐너 장애 시 첫 행동 세 가지는?

(1) 관객에게 안내 ("잠시 확인 중, 곧 재개") (2) 무전으로 파트 리더에 보고 (3) 예비 스캐너 요청. 임의 통과는 금지.
현장 체크
  • 검표기 배터리와 스캐너 사전 테스트
  • 매표소 / CS 데스크 위치 확인
  • 지연 관객용 임시 좌석 확보
03.2

좌석 안내

시나리오공연 시작 15분 뒤 지각 관객 도착. 좌석은 무대 앞 3열입니다.
실습

Q. 지각 관객을 바로 앞자리로 안내해도 될까요?

공연 중에는 원칙적으로 안 됨. 장면 전환이나 휴식 때 유도합니다. 그 전까지 로비 대기 또는 뒷줄 빈자리에 임시 착석.
현장 체크
  • 담당 구역 좌석 배치도 숙지
  • 휠체어 관객 명단 확인
  • 좌석 오류 시 매표소 직통 연락처 저장
03.3

특전회 (Hi-Touch / Photo)

시나리오Hi-Touch 중 한 관객이 아티스트 팔을 잡으려 합니다. 본인은 옆 라인 담당.
실습

Q. 위반 관객에게 안내할 한 문장을 적어보세요.

예: "고객님, 안전을 위해 신체 접촉은 삼가주세요. 다음 순서 안내드리겠습니다." 이유 + 존중 어투 + 다음 안내.
현장 체크
  • 참여권 + 신분증 대조
  • 손목 스탬프 도구 준비
  • 보안 인력 무전 채널 확인
Diagram / CS Script
컴플레인 응대 5단계
단계 목적 말할 문장
1. 경청 끝까지 듣기 "네, 말씀해주세요."
2. 공감 감정 인정 "많이 불편하셨겠어요."
3. 사실 확인 변명 없이 정보만 "티켓 번호 확인 부탁드립니다."
4. 해결 or 연결 본인 권한 or 담당자 "CS 데스크로 안내드릴게요."
5. 확인 결과 재확인 "이 방법으로 괜찮으실까요?"
"그건 저희 잘못 아닌데요" 는 컴플레인 악화 1순위. 감정이 격해진 관객은 조용한 공간으로 안내 + 물 제공. 폭언 시 혼자 대응하지 말고 보안을 부릅니다.
04 / Rehearsal

리허설과 공연 진행

콜타임은 도착 시간이 아니라 준비 완료 시간입니다.

Diagram / Call Time
공연 당일 흐름
콜타임은 도착이 아니라 "준비 완료" 시각. 지연 5분도 리허설을 압축시킵니다. 여유 있게 도착하세요.
04.1

콜타임과 도착

시나리오본인 콜타임 09:00. 지하철 이동 40분. 몇 시에 출발해야 할까요?
실습

Q. 못 맞출 것 같으면 어떻게 하나요?

즉시 매니저 / 파트 리더에 전화 + 예상 도착 시각 명시. "다 왔어요" 같은 모호한 표현은 금지.
현장 체크
  • 콜타임 10분 전 도착
  • 지연 시 즉시 전화
  • 본인 담당 큐 / 자리 사전 확인
04.2

큐 (Cue) 확인

시나리오드레스 리허설이 시작됐는데 본인 큐를 정확히 모릅니다. 매니저는 바쁩니다.
실습

Q. 큐를 모르는 상태로 리허설을 마쳐도 될까요?

절대 안 됨. 매니저 대신 파트 리더 / SM 에게 무전으로 재확인 요청. "모르겠어요" 를 감추면 본 공연에서 사고.
현장 체크
  • 큐시트 최신본 소지
  • 이슈 기록용 노트와 펜 지참
  • 리허설 후 이슈 목록 공유
05 / Comms

현장 커뮤니케이션

무전은 짧고 분명하게. 한 번에 한 사람만 말합니다.

05.1

무전기 사용

시나리오무전기를 처음 켰습니다. 상급자에게 위치와 상황을 보고하려 합니다.
실습

Q. 첫 무전 문장을 적어보세요 (상대 → 자기 → 용건 순).

예: "SM, 안내팀 3번 (본인 이름). 게이트 3 배치 완료. 이상 없음. Over." 상대 콜사인 → 자기 콜사인 → 용건 → Over.
현장 체크
  • PTT 1초 룰 (시작 전 / 끝난 후)
  • 이어폰 착용 (스피커 X)
  • 기본 용어 (Copy / Standby / Go / Over) 숙지
05.2

보고 (S / B / A / R)

시나리오게이트 3 에서 관객 실신. 대기 줄은 30분째. 상급자에게 무전 보고합니다.
실습

Q. 4단계 문장을 한 줄씩 적어보세요.

S (상황): 게이트 3, 관객 1명 실신. B (배경): 대기 30분, 스캐너 지연. A (판단): 저혈당 의심. R (요청): AED + 의료 인력 요청.
현장 체크
  • 보고 라인 (파트 리더 / SM / PM) 확인
  • 사실과 판단 구분해서 말하기
  • 감정어 (당황 / 무섭다) 배제

06 / Emergency

돌발 상황과 CS 대응

보고 → 판단 → 행동 순서를 바꾸지 마세요. 나쁜 소식일수록 빨리 알립니다.

06.1

공연 지연

시나리오음향 시스템이 멈춤. 복구까지 15분 예상. 관객이 웅성거리기 시작합니다.
실습

Q. "잠시만 기다려주세요" 는 왜 나쁜 안내인가요?

"잠시" 가 얼마인지 몰라서. 예: "음향 이슈로 약 15분 소요 예상. 5분 뒤 다시 안내드립니다." 예상 시간 + 다음 안내 시점을 함께 알립니다.
현장 체크
  • 이슈 인지 후 5분 이내 첫 안내
  • 이후 15분 간격 반복 안내
  • 상황 변화 시 즉시 업데이트
06.2

관객 컴플레인

시나리오관객이 "티켓 값에 비해 좌석이 너무 뒤다" 며 항의. 본인은 좌석 배정 권한이 없습니다.
실습

Q. 첫 문장을 적어보세요 (공감 + 다음 안내).

예: "자리가 아쉬우셨겠어요. 상황 확인해서 CS 데스크로 안내드릴게요. 잠시만 기다려주세요." 공감 + 연결 + 다음 안내.
현장 체크
  • "저희 잘못 아닌데요" 금지
  • "규정상 어쩔 수 없어요" 금지
  • 격해지면 조용한 공간으로 안내
06.3

우선순위 판단

시나리오동시에 발생: (1) 음향 볼륨 불만 3건 (2) 아티스트 도시락 부족 (3) 관객이 넘어져 발목 부상.
실습

Q. 세 건의 처리 순서와 이유를 적어보세요.

1) 부상 (안전이 최우선) 2) 음향 (공연 진행에 영향) 3) 도시락 (공연 뒤에도 해결 가능). 판단 기준은 "지금 안 하면 무엇이 커지는가".
현장 체크
  • 사람 안전 관련은 즉시 대응
  • 공연 진행 관련은 15분 안
  • 불편 사항은 공연 뒤 개선
06.4

인수인계

시나리오본인이 20분간 자리를 비워야 합니다. 인수자에게 무엇을 넘길까요?
실습

Q. 인수인계 3요소는?

(1) 진행 상황 (완료 / 진행 중) (2) 남은 이슈 (3) 다음 담당자 할 일. 무전 채널 / 콜사인도 함께 확인.
현장 체크
  • 교대 10분 전 후임 도착 확인
  • 인수인계 3요소를 노트에 기록
  • "이해했어요" 구두 확답 후 이동
Self-diagnosis

현장 투입 자가 진단 24문항

공연 현장에 가기 전, 아래 24개 항목을 스스로 체크합니다. 20개 이상이면 준비 완료.

사용 방법 / 각 문항에 "네" 라고 답할 수 있으면 체크. 못한 항목은 해당 챕터를 다시 읽으세요.

01 Safety (4문항)

  • 도착 즉시 확인할 것 4가지를 말할 수 있다
  • 관객 실신 시 첫 5초 행동 2가지를 안다
  • 정전 시 관객에게 하면 안 되는 말을 안다
  • 비상 대피 경로 2개 이상 확인한다

02 Artist (4문항)

  • 대기실 기본 세팅 5요소를 안다
  • 패스 없는 방문자 응대 문장을 말할 수 있다
  • 백스테이지 4가지 금지 행동을 안다
  • 아티스트와 마주쳤을 때 표준 행동을 안다

03 Audience (4문항)

  • 스캐너 장애 시 첫 행동 3가지를 안다
  • 지각 관객 안내 시점을 안다
  • 특전회 위반 관객 안내 문장을 말할 수 있다
  • 컴플레인 응대 5단계를 안다

04 Rehearsal (4문항)

  • 공연 당일 6단계 흐름을 안다
  • 콜타임 = 준비 완료 시각임을 안다
  • 지연 시 즉시 전화 원칙을 안다
  • 큐 모를 때 무전 재확인 요청을 안다

05 Comms (4문항)

  • PTT 1초 룰을 안다
  • 무전 호출 순서 (상대 → 자기 → 용건 → Over) 를 안다
  • SBAR 4단계 (S / B / A / R) 를 안다
  • 사실과 판단을 구분해 말할 수 있다

06 Emergency (4문항)

  • 지연 안내 15분 간격 원칙을 안다
  • 컴플레인 절대 금지 표현을 안다
  • 우선순위 판단 기준 (안전 우선) 을 안다
  • 인수인계 3요소를 안다
